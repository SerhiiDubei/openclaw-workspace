## 📝 Правило запису сесій (ДЛЯ ВСІХ КОРИСТУВАЧІВ!)

**При кожному повідомленні від користувача:**

1. **Ідентифікувати користувача** — визначити username з Telegram ID
2. **Перевірити час останнього повідомлення** — якщо > 30 хвилин, створити нову сесію
3. **Створити/відкрити файл сесії** — `memory/users/{username}/sessions/YYYY-MM-DD.md`
4. **Записати повідомлення одразу**:
   ```markdown
   ### HH:MM
   **[User]:** Текст повідомлення
   
   **[Assistant]:** Текст відповіді
   ```

**Правила:**
- Записувати КОЖНЕ повідомлення в реальному часі
- НЕ чекати кінця сесії
- Розбивати сесію якщо мовчання > 30 хвилин
