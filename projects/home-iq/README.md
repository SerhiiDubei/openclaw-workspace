# Home IQ — Lead Generation Copy System

## Overview
Home IQ is a premium lead generation copywriting system for home services marketplaces. It provides battle-tested, conversion-optimized copy templates for four core verticals:

- **Flooring** — installation, replacement, refinishing
- **Siding** — replacement, repair, exterior protection  
- **HVAC** — heating, cooling, system replacement
- **Home Security** — systems, monitoring, installation

## Philosophy
The ZIP-first approach: minimize friction, maximize trust, deliver comparison value.

## Structure
```
projects/home-iq/
├── copy/               # Page copy for each vertical
│   ├── flooring.md
│   ├── siding.md
│   ├── hvac.md
│   └── home-security.md
├── assets/             # Images, wireframes, references
└── docs/               # Research notes, methodology
```

## Copy Architecture (Universal Blocks)
1. **Hero** — H1/H2 + trust badges + ZIP form
2. **Icon Row** — 4 proof points (service-specific)
3. **Finished Projects** — social proof gallery
4. **Project Type** — segmentation selector
5. **How It Works** — 3-step marketplace flow
6. **Main Article** — educational content + benefits
7. **Reviews** — detailed customer testimonials
8. **FAQ** — comprehensive pricing and process answers
9. **Footer CTA** — final conversion push

## Key Metrics (Research-Backed)
- Flooring: $1,529–$4,852 project range, 1–2 day install
- Siding: $5,560–$17,710 range, 7–14 day timeline
- HVAC: $5,000–$22,000 range, 1 day install
- Home Security: $300–$1,238 range, DIY vs pro options

## Usage
Each vertical includes 5 tone variants:
- **Professional/Trustworthy** — risk reduction focus
- **Friendly/Local** — neighborhood contractor vibe
- **Premium/Luxury** — white-glove service
- **Budget/Value** — comparison shopping
- **Technical/Performance** — specs and efficiency

---
*Research based on 15-25 competitor pages per vertical across HomeAdvisor, Angi, Thumbtack, Home Depot, Lowe's, and regional installers.*
