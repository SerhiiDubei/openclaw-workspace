## 📋 Правила для цього проєкту

- Всі файли українською (якщо не вимагається інше)
- Назви файлів з датою: `YYYY-MM-DD-{description}.md`
- Кожна компанія — своя папка в `02-research/` і `03-cover-letters/`
- Конкретика з резюме, не загальні фрази
