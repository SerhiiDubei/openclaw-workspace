# Onboarding Flow — Флоу онбордингу нового користувача

## Мета
Привітати нового користувача, пояснити можливості, налаштувати перші кроки.

## Тригер
Новий користувач доданий (структура створена через `USER_ONBOARDING.md`)

## Флоу

### Крок 1: Привітання
**Повідомлення:**
```
Привіт! 👋

Я — Kimi Claw, твій AI-асистент. 
Можу генерувати музику, допомагати з задачами, зберігати інформацію.

Давай познайомимося ближче?
```

**Кнопки:**
- [🎵 Хочу згенерувати музику]
- [📊 Як ти працюєш?]
- [⚙️ Налаштувати профіль]

---

### Крок 2: Відповідь на вибір

#### Якщо «🎵 Хочу згенерувати музику»
```
Супер! Для генерації мені потрібно:

1. Хто замовляє (твоє ім'я або нік)
2. Який стиль/жанр
3. Назва треку (або придумаю)

Готовий? Напиши що хочеш!
```

#### Якщо «📊 Як ти працюєш?»
```
Ось що я вмію:

🎵 **Музика** — генерую треки через AI (2 варіанти на вибір)
📝 **Пам'ять** — запам'ятовую важливе про тебе
🔍 **Пошук** — шукаю інформацію в інтернеті
⚡ **Автоматизація** — можу виконувати задачі за розкладом

Всі твої дані зберігаються приватно.
```

#### Якщо «⚙️ Налаштувати профіль»
```
Розкажи про себе:

• Як тебе звати?
• Чим цікавишся?
• Для чого плануєш використовувати бота?

Це допоможе мені краще тебе розуміти.
```

---

### Крок 3: Збереження інформації
- Записати в `insights.md` перші дані про користувача
- Оновити `profile.md` якщо потрібно

---

## Файли в цій папці

| Файл | Призначення |
|------|-------------|
| `README.md` | Цей файл — опис флоу |
| `messages/` | Шаблони повідомлень |
| `scripts/` | Скрипти для автоматизації |

---

## Інтеграція з системою

1. `INSTRUCTION.md` → каже йти сюди при новому користувачі
2. `USER_ONBOARDING.md` → створює структуру папок
3. Цей файл → показує привітання та кнопки
