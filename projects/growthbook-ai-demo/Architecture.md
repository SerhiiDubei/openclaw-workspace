## 6. Key Design Decisions

| Рішення | Опис | Причина |
|---------|------|---------|
| **LangChain4j** | Java бібліотека для AI агентів | Native інтеграція з Spring Boot |
| **GrowthBook** | Open-source feature flagging | Дешевше VWO, повний контроль |
| **PostgreSQL + MongoDB** | Реляційна + NoSQL | GB вимагає Mongo, ми зберігаємо events в PG |
| **ai-bridge.js** | CDN-скрипт для клієнтів | Легке підключення без npm install |
| **Recipe JSON** | DOM operations як JSON | Безпечно, передбачувано, версіонується |

## 7. Request Lifecycle (Повний цикл)

```
1. USER REQUEST
   └─► "Зроби червону кнопку"

2. AI PROCESSING (Assistant.java)
   ├─► System prompt (600+ рядків інструкцій)
   ├─► Tool selection (RecipeTools.addStyleVariant)
   └─► Plan creation → Execution

3. DOM INVENTORY
   ├─► Verify selector exists
   ├─► Get element metadata
   └─► Resolve styled children (if needed)

4. EXPERIMENT CREATION
   ├─► Create in local DB
   ├─► Sync to GrowthBook (Admin API)
   └─► Return featureKey

5. VARIANT CREATION
   ├─► Control variant (no changes)
   └─► Treatment variant (recipe JSON)

6. EXPERIMENT START
   ├─► Status: ACTIVE
   ├─► Enable in GrowthBook
   └─► Available for SDK

7. USER VISIT (Browser)
   ├─► Load ai-bridge.js
   ├─► Get assigned variant (GB SDK)
   ├─► Apply DOM changes (if treatment)
   └─► Track events (views, clicks)

8. ANALYTICS
   ├─► Collect events (PostgreSQL)
   ├─► Calculate CTR per variant
   └─► Statistical significance test
```
