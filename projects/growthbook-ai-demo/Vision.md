# Vision: GrowthBook AI Automation Platform

## Місія

Полегшення роботи команд з запуску A/B-тестів через AI-агента, який автоматизує створення, запуск та аналіз експериментів.

---

## Фази розвитку

### Phase 1: MVP (Вихід на ринок)

**Термін:** Найближчий час  
**Фокус:** Ручне керування з AI-асистуванням

#### Що робить
- AI-агент через чат інтерфейс створює та запускає A/B тести
- Робота з простими лендінгами (Landing Pages)
- Базові косметичні зміни:
  - Шрифти (font styles, sizes)
  - Тексти (headings, buttons, descriptions)
  - Картинки (hero images, icons, backgrounds)
  - Поп-апи (додавання/видалення)

#### Human-in-the-loop
- **Верифікація:** Людина візуально перевіряє зміни перед запуском
- **Контроль:** 90% процесів контролюється командою
- **AI як помічник:** Виконує "під капотом" технічну роботу

#### Технічний флоу (3 етапи)

**Етап 1: Підключення**
- Розміщення smart-copy скрипта на лендінгу
- Отримання доступу до DOM

**Етап 2: Інвентаризація**
- Автоматична детекція змінюваних елементів
- Ідентифікація: кнопки, заголовки, картинки, текстові блоки

**Етап 3: Інтеграція з GrowthBook**
- Створення фіч (features)
- Створення експериментів
- Розподіл трафіку (traffic allocation)
- Зберігання конфігурації в БД

#### Приклади запитів до AI
> "Запусти експеримент, де колір CTA-кнопки зміниться з синього на помаранчевий"

> "Заміни hero-картинку на цій сторінці"

> "Створи A/B тест з 4 варіантами заголовків, розподіли трафік порівну"

#### Аналітика
- Збір даних (views, clicks, conversions)
- Ручний аналіз результатів командою

---

### Phase 2: MVP+ / Mini-Product (3-6 місяців)

**Термін:** 3-6 місяців (±півроку)  
**Фокус:** Автономність агента

#### Автономний AI Agent
- Самостійний аналіз сайту (crawl + analyze)
- Автоматична генерація гіпотез для тестування
- Пропозиція змін без прямого запиту користувача

#### Розширена архітектура агента
- Deep context understanding сайту
- Аналіз конверсійних елементів
- Рекомендації на основі best practices

#### Автоматизована аналітика
- Автоматичний аналіз зібраних даних
- Статистична значущість (p-value, confidence intervals)
- Автоматичні звіти з рекомендаціями

#### Розширений функціонал UI
- Складніші DOM-маніпуляції
- Multi-element changes
- Dynamic content testing

---

### Phase 3: Long-term (1+ рік)

**Термін:** 1 рік+

## Контекст використання

### Зараз (MVP)
Компанія з афіліат-маркетингу, яка тестує прості лендінги з базовими змінами.

### Ключові переваги
1. **Швидкість:** AI робить технічну робту замість команди
2. **Простота:** Чат-інтерфейс замість складних dashboards
3. **Безпека:** Human verification перед запуском
4. **Інтеграція:** Пряма робота з GrowthBook API

---

## Success Metrics

### MVP
- [ ] AI успішно створює експерименти з текстових запитів
- [ ] Human verification працює перед кожним запуском
- [ ] Інвентаризація елементів працює автоматично
- [ ] Інтеграція з GrowthBook стабільна

### MVP+
- [ ] AI сам пропонує гіпотези (≥5/тиждень)
- [ ] Автоматичний аналіз даних з actionable insights
- [ ] Час від ідеї до запуску < 5 хвилин
