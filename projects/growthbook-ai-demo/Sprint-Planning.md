## Тул для менеджменту: Пропозиція

### Option 1: GitHub Projects (Рекомендовано для старту)
**Плюси:**
- Вже є репозиторій
- Інтеграція з кодом
- Безкоштовно
- Просто для маленької команди

**Мінуси:**
- Слабкіший трекінг часу
- Обмежена звітність

### Option 2: ClickUp
**Плюси:**
- Гнучкість
- Time tracking
- Дашборди

**Мінуси:**
- Ще один інструмент
- Навчання команди

### Option 3: Jira
**Плюси:**
- Стандарт для enterprise
- Потужна звітність

**Мінуси:**
- Складний для малої команди
- Платний

**Рекомендація:** Почати з GitHub Projects → перейти на ClickUp при масштабуванні

## Спринт 1 (Поточний тиждень)

**Дати:** 4-11 квітня 2026  
**Ціль:** Підготовка до ринкового тесту

### Задачі

#### Сергій (Product)
- [ ] **Вибрати 1-3 лендінги** для Phase 1 тесту
  - Критерії: vanilla JS, проста структура, є трафік
  - Дедлайн: Середа
  
- [ ] **Домовитись з 1-2 командами байерів**
  - Умови тестування, обсяг трафіку
  - Дедлайн: П'ятниця

- [ ] **Інтеграція Михайла Мольського**
  - Онбордінг, ознайомлення з документацією
  - Дедлайн: Понеділок (наступний спринт)

#### Михайло (Delivery Manager) — стартує цього тижня
- [ ] **Онбордінг**
  - Прочитати Vision, Roadmap
  - Зустріч з Сергієм (синхронізація очікувань)
  
- [ ] **Налаштування системи трекінгу**
  - Вибір тулу (GitHub Projects vs ClickUp)
  - Створення темплейтів задач
  
- [ ] **Перший спринт-планінг**
  - Зустріч з командою
  - Розподіл задач на спринт 2

#### Антон (Dev)
- [ ] **AI Stress Testing**
  - Запуск 20-50 parallel тестів
  - Документація результатів
  - Дедлайн: Четвер
  
- [ ] **Fix issues з stress testing**
  - Якщо знайдено баги — фікс
  - Дедлайн: Неділя

#### Віталій (Lead Dev)
- [ ] **Endpoint Mapping**
  - Документація всіх API методів
  - Swagger/OpenAPI специфікація
  - Дедлайн: Середа
  
- [ ] **Code Review Антонових змін**
  - Рев'ю stress testing коду
  - Дедлайн: П'ятниця

#### Юля (QA)
- [ ] **Тест-кейси для Phase 1**
  - Написати 10-15 тест-кейсів
  - Формат: Given → When → Then
  - Дедлайн: Четвер
  
- [ ] **Ручне тестування базового флоу**
  - Зміна кольору кнопки
  - Зміна тексту
  - Документація результатів
  - Дедлайн: П'ятниця

#### ML Команда
- [ ] **Синхронізаційний дзвінок**
  - Обговорення поточної архітектури

  - Дедлайн: Вівторок/Середа
