## 3. Фази Roadmap

### Phase 0: Foundation (Зараз)
**Термін:** Поточний момент  
**Фокус:** Стабілізація, тестування, підготовка

#### Задачі:
- [ ] **QA Setup** (Юля)
  - Описати конкретні тест-кейси
  - Визначити критерії прийняття
  - Домовитись про формат співпраці

- [ ] **AI Stress Testing** (Антон)
  - Запуск 20-50 фіч одночасно
  - Перевірка на помилки та race conditions
  - Результати: чи витримує система навантаження

- [ ] **Endpoint Mapping**
  - Візуалізувати всі доступні ендпоінти
  - Документація методів
  - Тестування кожного методу в різних варіаціях

- [ ] **ML Team Review**
  - Дзвінок з ML командою
  - Обговорення bottlenecks
  - План оптимізації

- [ ] **Smart Code Extended Testing**
  - Тест на різних типах сайтів
  - Перевірка безпеки підключення

---

### Phase 1: Real Market Test (Наступний глобальний крок)
**Термін:** 2 тижні - 2 місяці  
**Фокус:** Валідація на реальному трафіку

#### Підготовка:
- [ ] **Вибір лендінгів**
  - 1-3 лендінги (vanilla landing page, max з поп-апом)
  - Прості сторінки для початку
  - Перевірка роботи DOM inventory

- [ ] **Домовленість з байерами**
  - 1-2 команди байерів
  - Домовленість про трафік
  - Умови тестування

- [ ] **Manual Verification Process**
  - Процес ручної перевірки змін
  - Хто перевіряє: QA + Product
  - Формат звітів

#### Виконання:
- [ ] **Launch Tests**
  - Підключення системи до лендінгів
  - Запуск A/B тестів через AI агента
  - Щоденний моніторинг

- [ ] **Data Collection**
  - Збір результатів тестів
  - Виміри: CTR, конверсія, статистична значущість
  - Порівняння з контролем

- [ ] **Dashboard v1**
  - Простий дашборд для перегляду результатів
  - Базові метрики
  - Візуалізація для клієнтів

#### Success Criteria:
- [ ] Система стабільно працює з реальним трафіком
- [ ] AI успішно запускає тести без ручного втручання
- [ ] Результати тестів статистично значущі
- [ ] Команда байерів бачить value

## 4. Технічні обмеження (Known Limitations)

| Обмеження | Вплив | План |
|-----------|-------|------|
| Vanilla JS only | Не працює на React/Vue/Angular без тестування | Phase 1: тест на vanilla, потім розширення |
| Картинки не тестували | Немає AI image variant | Phase 0: додати в тест-план |
| Human verification required | Не повна автономність | Phase 1: manual, Phase 2: автоматична валідація |
| 20-50 parallel tests | Невідомо, чи витримає система | Phase 0: stress testing Антона |
