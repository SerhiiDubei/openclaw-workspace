## 🤔 Що це взагалі таке?

Уявіть, що ви власник магазину. Кожного дня до вас заходять люди, дивляться товари, щось купують. Ви бачите, скільки людей прийшло, що купили, які товари популярні.

**Google Ads Conversion Tracking** — це такий собі "електронний продавець", який записує:
- Хто прийшов з реклами Google
- Що робив на сайті
- Чи купив/зареєструвався/клікнув
- Скільки грошей це принесло

А потім каже Google: "Ей, ця твоя реклама спрацювала! Ось конверсія!"

### Аналогія з реальним життям

```

│                                                                 │
│  META PIXEL = Детектив з фотографією 🔍                        │
│                                                                 │

│  • Фотографує кожного, хто заходить в магазин                  │
│  • Потім порівнює зі своїми фото ("О, це наш клієнт!")        │
│  • Проблема: люди можуть приховати обличчя (ad-blockers)       │
│                                                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  GOOGLE ADS API = Детектив з реєстром 📋                       │
│                                                                 │
│  • Сидить у відділенні поліції з базою даних                   │
│  • Отримує повідомлення: "Особа #12345 щойно купила носки"    │
│  • Перевіряє по базі: "Ага, це той, хто бачив нашу рекламу!"  │
│  • Перевага: працює навіть якщо людина в маску (інкогніто)    │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### Технічне порівняння

| Функція | Meta Pixel | Google Ads API |
|---------|------------|----------------|
| **Як працює** | Браузерний скрипт | Серверний API |
| **Надійність** | 60-70% (ad-blockers) | 95%+ (server-side) |
| **ID трекінгу** | fbclid | gclid |
| **Fallback** | CAPI (server-side) | Enhanced Conversions |
| **Найкраще для** | Social discovery | Intent-based search |
| **Складність** | Легко | Складніше |

### Коли що використовувати

**Meta Pixel (Facebook/Instagram):**
- ✅ Коли люди ще не знають, що їм потрібно
- ✅ Візуальні продукти (одяг, їжа, декор)
- ✅ Lookalike audiences
- ✅ Retargeting

**Google Ads:**
- ✅ Коли люди шукають конкретно
- ✅ Високий intent ("купити айфон 15")
- ✅ B2B продукти
- ✅ Local services

**Best practice:** Використовувати обидва! 🎯

## 🆔 GCLID vs fbclid: Битва ID

### Що це таке?

Це як **номери білетів** на концерт. Кожен, хто клікнув на рекламу, отримує унікальний номер.

```
┌─────────────────────────────────────────────────────────────────┐
│  🔗 URL з реклами Google:                                       │
│  https://site.com/?gclid=CjwKCAjw...xyz123                     │
│                    ─────────────                                │
│                    Ось він! Унікальний ID кліку                │
│                                                                 │
│  🔗 URL з реклами Meta:                                         │
│  https://site.com/?fbclid=IwAR2a...abc456                      │
│                    ──────────────                               │
│                    Унікальний ID для Facebook                  │
└─────────────────────────────────────────────────────────────────┘
```

### Навіщо це потрібно?

**Сценарій:**
1. Олена клікає на вашу Google рекламу о 10:00
2. Їй присвоюється GCLID: `ABC123`
3. Вона не купує, але запам'ятовує сайт
4. О 19:00 вона повертається (через закладки) і купляє
5. Google бачить: "Ага, GCLID ABC123 конвертував!"
6. Google зараховує конверсію тій самій рекламі

**Без GCLID:** Google думає, що це був "прямий візит" і не бачить зв'язку з рекламою.

### Термін життя

| ID | Термін зберігання | Що відбувається після |
|----|-------------------|----------------------|
| **GCLID** | 90 днів | Конверсія все ще зарахується, але без прив'язки до кліку |
| **fbclid** | 28 днів (клік), 1 день (view) | Атрибуція втрачається |

### Як зберегти GCLID

**Простий код для сайту:**

```javascript
// Цей код зберігає GCLID в cookie на 90 днів

function saveGCLID() {
    // 1. Шукаємо GCLID в URL
    const urlParams = new URLSearchParams(window.location.search);
    const gclid = urlParams.get('gclid');
    
    if (gclid) {
        // 2. Зберігаємо в cookie
        const expires = new Date();
        expires.setDate(expires.getDate() + 90); // 90 днів
        
        document.cookie = `gclid=${gclid};expires=${expires.toUTCString()};path=/`;
        
        console.log('✅ GCLID збережено:', gclid);
    }
}

// Запускаємо при завантаженні
saveGCLID();
```

## ✨ Enhanced Conversions: Суперсила Google

### Що це?

**Enhanced Conversions** = Google Ads на стероїдах 💪

Звичайний трекінг: "Хтось клікнув → Хтось купив"  
Enhanced: "ivan@email.com клікнув → ivan@email.com купив айфон за $999"

### Як це працює (простими словами)

```
┌─────────────────────────────────────────────────────────────────┐
│  КОРИСТУВАЧ                                                     │
│  • Заходить на сайт                                             │
│  • Вводить email: ivan@example.com                             │
│  • Купляє товар                                                 │
│                                                                 │
│         ↓                                                       │
│                                                                 │
│  ВАШ СЕРВЕР                                                     │
│  • Отримує: ivan@example.com + $999 + Product ID               │
│  • Хешує email: a3f5b2d8e...                                   │
│  • Відправляє в Google Ads API                                 │
│                                                                 │
│         ↓                                                       │
│                                                                 │
│  GOOGLE                                                         │
│  • Бачить: "Користувач a3f5b2d8e купив за $999"                │
│  • Перевіряє: "О, цей хеш відповідає користувачеві,           │
│    який бачив нашу рекламу о 10:00!"                          │
│  • Зараховує конверсію ✅                                       │
└─────────────────────────────────────────────────────────────────┘
```

### Чому це круто?

| Без Enhanced | З Enhanced |
|--------------|------------|
| Втрачається 30-40% конверсій | Відновлюється 20-30% |
| Неповна картина | Повна attribution |
| Немає даних для оптимізації | Краще machine learning |

### Що можна надсилати?

✅ **Email** (хешований)  
✅ **Phone** (хешований)  
✅ **Ім'я + Адреса** (хешовані)  
✅ **Conversion value**  
✅ **Currency**  
✅ **Transaction ID**

❌ **Ніколи:** сирі дані, паролі, дані карток

### Privacy 🔒

- Всі PII (особисті дані) **хешуються** (SHA-256)
- Google не бачить реальний email
- Користувач може відмовитися (Consent Mode)
- GDPR/CCPA compliant

```
│  ─────────────────────                                          │
│  • Один скрипт для всіх Google продуктів                       │
│  • Google Ads + Analytics + Floodlight + ...                   │

│      'currency': 'USD'                                         │
│    });                                                         │
│  </script>                                                     │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│  GOOGLE TAG MANAGER (GTM)                                       │
│  ────────────────────────                                       │
│  • Контейнер для всіх тегів                                    │
│  • Не треба лізти в код для змін                               │

┌─────────────────────────────────────────────────────────────────┐
│  GOOGLE ADS API (Server-side)                                   │
│  ────────────────────────────                                   │
│  • Ніякого JavaScript в браузері                               │
│  • Пряме з'єднання сервер ↔ Google                             │
│  • Найнадійніший метод                                         │
│  • Потрібен програміст                                         │
│                                                                 │
│  Приклад (Python):                                              │
│  google_ads_client.upload_click_conversion(                    │
│      gclid="ABC123",                                           │
│      conversion_value=50.0,                                    │
│      currency="USD"                                            │
│  )                                                             │
└─────────────────────────────────────────────────────────────────┘
```

| Ситуація | Рекомендація |

| Багато тегів (Ads, Analytics, FB) | Google Tag Manager |
| Важлива точність, high-value продукт | Google Ads API |
| Ad-blockers критичні | Server-side GTM або API |

## 🔄 Прокидування Конверсій через Postback

### Що таке Postback?

**Аналогія:**
- Ви посилаєте друга в магазин з вашою карткою лояльності
- Він купляє, показує картку
- Магазин надсилає ВАМ SMS: "Ваш друг купив, вам нараховано бонуси"

**В affiliate маркетингу:**
1. Ви надсилаєте користувача на партнерський сайт (з вашим ID)
2. Користувач щось робить (реєструється, платить)
3. Партнер надсилає postback: "Ваш ID #123 зробив конверсію, payout $50"
4. Ви пересилаєте це в Google Ads

### Схема роботи

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│  КОРИСТУВАЧ          ВАШ САЙТ         ПАРТНЕР       GOOGLE    │
│     │                    │                │            │       │
│     │ 1. Клік на рекламу │                │            │       │
│     │◄───────────────────│                │            │       │
│     │                    │                │            │       │
│     │ 2. Бачить огляд    │                │            │       │
│     │◄───────────────────│                │            │       │
│     │                    │                │            │       │
│     │ 3. Клікає на партнера              │            │       │
│     │───────────────────►│                │            │       │
│     │   (з вашим ID)     │                │            │       │
│     │                    │                │            │       │
│     │ 4. Реєструється    │                │            │       │
│     │─────────────────────────────────────►│            │       │
│     │                    │                │            │       │
│     │                    │ 5. POSTBACK    │            │       │
│     │                    │◄───────────────│            │       │
│     │                    │   "Конверсія!" │            │       │
│     │                    │                │            │       │
│     │                    │ 6. Пересилаємо │            │       │
│     │                    │───────────────►│            │       │
│     │                    │   в Google     │            │       │
│     │                    │                │            │       │
│     │                    │                │            │  ✅   │
│     │                    │                │            │       │
└─────────────────────────────────────────────────────────────────┘
```

### Приклад Postback URL

**Що надсилає партнер:**

```
https://your-site.com/webhook/partner-conversion?
    click_id=ABC123&
    conversion_type=registration&
    payout=5.00&
    currency=USD&
    status=approved&
    timestamp=2026-04-06T10:30:00Z
```

**Що робить ваш сервер:**

```python
def handle_postback(request):
    # Отримуємо дані
    gclid = request.get('click_id')
    payout = request.get('payout')
    
    # 1. Зберігаємо у свою БД
    save_conversion(gclid, payout)
    
    # 2. Негайно відправляємо в Google Ads
    send_to_google_ads(
        gclid=gclid,
        conversion_value=payout,
        currency='USD'
    )
    
    return {"status": "success"}
```

### Чому це важливо?

| Без Postback | З Postback |
|--------------|------------|
| Google знає тільки про клік | Google знає про конверсію |
| Не може оптимізувати | Оптимізує на конверсії |
| Витрачає бюджет на "поганих" | Фокус на "хороших" |
| ROAS невідомий | ROAS відомий і growing |

### Налаштування Postback (покроково)

**Крок 1:** Отримайте postback URL від партнера
- Зазвичай виглядає: `https://yoursite.com/postback?clickid={gclid}&payout={amount}`

**Крок 2:** Передайте GCLID партнеру
```javascript
// При кліку на партнерський лінк
function goToPartner(partnerUrl) {
    const gclid = getCookie('gclid');
    const fullUrl = `${partnerUrl}?subid=${gclid}`;
    window.location = fullUrl;
}
```

**Крок 3:** Прийміть postback
- Створіть endpoint на своєму сервері
- Зберігайте дані
- Передайте в Google Ads

**Крок 4:** Налаштуйте Google Ads
- Створіть Conversion Action (тип: Website)
- Увімкніть Enhanced Conversions (опціонально)
- Перевірте в Debug mode

## ❓ FAQ (Питання, які задають усі)

### Q: Чому мої конверсії не збігаються з реальними?

**A:** Найпоширеніші причини:
1. Ad-blockers (15-25% втрат) → Використовуйте server-side
2. iOS 14.5+ обмеження → Використовуйте Consent Mode
3. Різниця в часових зонах → Використовуйте UTC
4. Deduplication issues → Перевірте order_id

### Q: Скільки часу зберігати GCLID?

**A:** Максимум 90 днів. Після цього:
- Конверсія зарахується (якщо в attribution window)
- Але не буде прив'язана до конкретного кліку
- Google використає моделювання

### Q: Чи потрібен мені програміст?

**A:** Залежить від рівня:
- **Базовий** (Google Tag): Ні, вистачить copy-paste
- **Середній** (GTM): Бажано, але можна самому
- **Advanced** (API): Так, потрібен backend developer

### Q: Що краще: Google Ads чи Meta для dating?

**A:** **Обидва!** 💪
- **Google**: Люди активно шукають "best dating sites"
- **Meta**: Люди "не проти познайомитися", але не шукають
- **Співвідношення**: 60% Google, 40% Meta (для dating)

### Q: Що таке Consent Mode v2?

**A:** Нове правило Google для ЄС:
- Спочатку запитуєте згоду на cookies
- Якщо відмовились — теги працюють в обмеженому режимі
- Google моделює "втрачені" конверсії
- **Обов'язково з березня 2024!**

### Q: Як перевірити, що все працює?

**A:** Кроки:
1. Відкрийте Tag Assistant
2. Знайдіть своє оголошення
3. Клікніть (витратите $0.01, але це того варте 😉)
4. Зробіть конверсію
5. Перевірте в Real-time reports
6. Чекайте 3-24 години для звичайних звітів
