## 🎯 Механіка #1: Персоналізація Рекомендацій

### Концепція

Замість того щоб показувати всім однаковий список dating сайтів — підбираємо ідеальний match для кожного користувача за 60 секунд.

**Як працює:**
1. Користувач заходить на сайт
2. Бачить запрошення пройти короткий квіз (3-5 питань)
3. Отримує персоналізовані рекомендації
4. Кожна рекомендація обґрунтована його відповідями

### Питання квізу (приклад)

```
│                                                              │

└─────────────────────────────────────────────────────────────┘
```

**Питання:**
1. **Relationship goal** — серйозні стосунки / дружба / веселощі / ще не знаю
2. **Age range** — 18-25 / 26-35 / 36-45 / 45+
3. **Location preference** — локально / онлайн / неважливо
4. **Budget** — безкоштовно / до $20/міс / до $50/міс / гроші не проблема
5. **Deal breakers** — хочу верифікацію / без фейків / ЛГБТQ+ friendly

### Алгоритм підбору

```python
# Приклад логіки matching

def match_dating_sites(user_preferences):
    matches = []
    
    for site in database:
        score = 0
        
        # Goal matching (40% weight)
        if site.primary_goal == user_preferences['goal']:
            score += 40
        elif site.supports_goal(user_preferences['goal']):
            score += 20
            
        # Age demographics (20% weight)
        if user_preferences['age'] in site.target_demographics:
            score += 20
            
        # Price fit (20% weight)
        if site.price_range <= user_preferences['budget']:
            score += 20
        elif site.has_free_tier:
            score += 10
            
        # Feature matching (20% weight)
        matching_features = len(
            set(site.features) & set(user_preferences['must_haves'])
        )
        score += matching_features * 5
        
        if score >= 60:  # Threshold
            matches.append({
                'site': site,
                'score': score,
                'match_reasons': generate_reasons(site, user_preferences)
            })
    
    return sorted(matches, key=lambda x: x['score'], reverse=True)[:3]
```
