## Ролі та обов'язки

### PM (Prime Minister)
- [ ] Визначення теми (definition)
- [ ] Фрейм (frame)
- [ ] 2-3 аргументи "за"
- [ ] Задає тон усьому раунду

### LO (Leader of Opposition)
- [ ] Ребутал PM (мінімум 2 точки)
- [ ] Може оскаржити definition
- [ ] Власні аргументи "проти"
- [ ] Фрейм опозиції

### DPM (Deputy PM)
- [ ] Ребутал LO
- [ ] Захист PM від критики
- [ ] Розширення кейсу уряду

### DLO (Deputy LO)
- [ ] Ребутал DPM
- [ ] Захист LO
- [ ] Розширення кейсу опозиції

### MG (Member of Government)
- [ ] **Extension** — новий рівень аргументації
- [ ] Ребутал OO
- [ ] Не повторювати OG

### MO (Member of Opposition)
- [ ] **Extension** опозиції
- [ ] Ребутал MG
- [ ] Не повторювати OO

### GW (Government Whip)
- [ ] Підсумок дебату
- [ ] Захист extension
- [ ] Фрейм для суддів
- [ ] Без нових аргументів

### OW (Opposition Whip)
- [ ] Підсумок дебату
- [ ] Захист extension
- [ ] Фрейм для суддів
- [ ] Без нових аргументів

## POI (Points of Information)

### Коли можна
- Після 1-ї хвилини виступу
- До 6-ї хвилини виступу

### Механіка
1. Опозиційний спікер: "Point"
2. Поточний спікер: приймає (кивок) або відхиляє ("No, thank you")
3. Якщо прийнято — питання до 15 секунд
4. Спікер може відповісти або сказати "I'll take that in my speech"

### Стратегічні моменти
- POI в 1-шу хвилину — агресивно, ризиковано
- POI в останню допустиму хвилину — може збити ритм
- Прийняти POI і знищити питання = + до авторитету

## Переможні стратегії

### Для OG
- Сильний фрейм, який протримається
- Аргументи, які CG може розвинути
- Не вичерпати всю тему

### Для CG
- Справжній extension (новий рівень)
- Не "ножити" OG (не критикувати партнерів)
- Показати, що без вас уряд програв би

### Для OO
- Ребутал PM — чіткий і руйнівний
- Власна лінія аргументації
- Фрейм, що конкурує з урядовим

### Для CO
- Extension опозиції
- Сильний підсумок
- Показати єдність опозиції
