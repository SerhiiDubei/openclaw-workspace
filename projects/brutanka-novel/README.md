# BRITANKA NOVEL ENGINE
## Система дебатів для художньої новели

---

## Архітектура

```
projects/brutanka-novel/
├── system/           # Ядро системи (правила, механіки)
├── agents/           # Персонажі-гравці (профілі, стилі, пам'ять)
├── scenarios/        # Сценарії (теми, проблеми, контексти)
└── scripts/          # Скрипти для запуску раундів
```

---

## Як це працює

### 1. SYSTEM — правила гри
Тут живуть чисті механіки Британки:
- Порядок виступів
- Таймінг
- POI механіка
- Суддівство
- Підрахунок балів

**Це незмінне ядро.** Як шахові правила.

### 2. AGENTS — персонажі
Кожен агент = персонаж з:
- Ім'ям та бексторі
- Стилем гри (агресивний, аналітичний, харизматичний...)
- Сильними/слабкими сторонами
- Пам'яттю про попередні дебати
- Рейтингом

### 3. SCENARIOS — світ новели
- Теми дебатів вписані в сюжет
- Проблеми, що рухають історію
- Контекст: де, коли, чому ці персонажі сперечаються

### 4. SCRIPTS — запуск
- Генерація раундів
- Логування діалогів
- Розвиток сюжету за результатами

---

## Приклад інтеграції

**Сюжет:** Академія дебатів, де студенти змагаються за грант на навчання в Оксфорді.

**Персонажі:**
- Макс — технар, аналітик, слабкий в харизмі
- Софія — харизматична лідерка, слабка в логіці
- Давид — баланс, але нервує під тиском
- ...і ще 5 персонажів

**Раунд:** Тема "Цей дім вважає, що AI має право на авторство". 

Система Британки запускає дебат → агенти грають за своїми профілями → результат впливає на сюжет (хто проходить далі, хто з ким зближується/свариться).

## Мета

Поєднати глибину дебатних механік з емоційною оповіддю. 
Глядач читає драматичну сцену, але під капотом — справжня гра з правилами, стратегіями і несподіваними результатами.
