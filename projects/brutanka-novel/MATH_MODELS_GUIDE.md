# Математичні моделі для істориків та гуманітаріїв

## Вступ

Матмодель — це не формула, яку треба зубрити. Це **спосіб описати складну систему простими словами**, щоб комп'ютер міг її "програвати".

---

## Що таке математична модель?

**Проста аналогія:**

> Модель — це як макет будинку. Не справжній будинок, але показує головне: де кімнати, яке планування, де сонце вранці. За макетом можна зрозуміти, чи зручно житиме, не будуючи справжній будинок.

**Для чого потрібна:**
- Перевірити ідею без реальних витрат
- Побачити, що станеться "якщо..."
- Знайти оптимальне рішення

---

## Типи моделей

### 1. Детерміністичні vs Стохастичні

**Детерміністична** — як годинник:
- Ввів дані → отримав точний результат
- Приклад: `Відстань = Швидкість × Час`
- Якщо їхати 60 км/год 2 години — точно 120 км

**Стохастична** — як метеопрогноз:
- Ввів дані → отримав ймовірність
- Приклад: "Ймовірність дощу завтра — 70%"
- Не гарантує, але дає найкращу оцінку

**Аналогія:**
- Детерміністична = шахи без суперника (ти сам розраховуєш ходи)
- Стохастична = покер (не знаєш карти суперника, але можеш оцінити шанси)

---

### 2. Дискретні vs Неперервні

**Дискретна** — події відбуваються "кроками":
- Приклад: черга в магазині (1 людина, 2 людини...)
- Час: 0 → 1 → 2 → 3 хвилини

**Неперервна** — події плавні:
- Приклад: температура повітря (змінюється плавно)
- Час: будь-який момент між 0 і 1 хвилиною

**Аналогія:**
- Дискретна = фільм (24 кадри за секунду, але ми бачимо рух)
- Неперервна = реальність (рукою махнув — плавний рух)

---

### 3. Агентні моделі

**Що це:** Система, де багато "агентів" (суб'єктів) взаємодіють за правилами.

**Приклади:**
- Мурашник (кожна мураха — агент, разом будують складну колонію)
- Трафік (кожен водій — агент, разом створюють пробки)
- Ринок (кожен трейдер — агент, разом формують ціни)

**Аналогія:**
> Футбол. 22 гравці — 22 агента. Кожен має свої цілі (забити/не пропустити), правила (не офсайд), стратегію. Разом виходить гра, яку неможливо передбачити, знаючи тільки правила.

**Для Britanka:**
- 8 агентів-дебатерів
- Кожен зі своїм CORE (характеристиками) і SOUL (особистістю)
- Взаємодіють за правилами Британки
- Результат — унікальний раунд кожен раз

## Ключові концепції

### Ймовірність

**Що це:** Міра впевненості, що подія станеться.

**Приклади з життя:**
- "Ймовірність, що автобус запізниться — 20%"
- "У цього гравця 80% влучень з лінії штрафного"

**Аналогія:**
> Кубик. Ймовірність випасти 6 — 1/6 ≈ 16.7%. Не означає, що раз на 6 кидків точно буде 6. Означає: якщо кинути 600 разів, приблизно 100 разів випаде 6.

### Функція

**Що це:** Правило, яке перетворює вхід у вихід.

**Приклад:**
- Вхід: кількість годин сну
- Функція: `бадьорість = f(сон)`
- Вихід: наскільки ти бадьорий

**Аналогія:**
> Кавоварка. Вхід — кавові зерна + вода. Функція — приготування. Вихід — еспресо. Не знаючи, як влаштована кавоварка, але знаючи, що вона робить.

### Оптимізація

**Що це:** Пошук найкращого рішення.

**Приклад:**
- Як розподілити бюджет, щоб максимізувати прибуток?
- Який маршрут найкоротший?

**Аналогія:**
> Лабіринт. Є багато шляхів, але тільки один найкоротший. Оптимізація — це пошук цього шляху без перебору всіх (бо їх мільйони).

## Моделі для Britanka

### Модель агента

```
Агент = (SOUL, CORE, Пам'ять)

CORE = {
  cooperation_bias: [0-100],      // наскільки командний гравець
  deception_tendency: [0-100],    // наскільки хитрий/агресивний
  strategic_horizon: [0-100],     // наскільки далекоглядний
  risk_appetite: [0-100]          // наскільки готовий ризикувати
}
```

**Як це працює:**
- Високий `deception_tendency` → частіше перебиває (POI)
- Високий `cooperation_bias` → краще підтримує партнера
- Це не жорсткі правила, а **схильності** — як у людей

### Модель оцінки

```
Score(виступ) = 
  0.4 × Content(аргументи) + 
  0.25 × Rebuttal(спростування) + 
  0.25 × Structure(структура) + 
  0.10 × Style(стиль)
```

**Що це:** Ваги показують, що важливіше для суддів. Не випадкові числа — типові для реальних дебатів.

### Стохастична модель POI

```
P(агент_переб'є) = f(
  deception_tendency_агента,
  слабкість_поточної_промови,
  timing
)
```

**Що це:** Ймовірність, що агент переб'є, залежить від його характеру і ситуації. Не "переб'є обов'язково", а "швидше за все, переб'є".

---

## Чому це працює

**Парадокс:** Прості правила створюють складну поведінку.

**Приклад — мурашник:**
- Правило 1: Якщо знайшов їжу — неси в мурашник і залишай слід
- Правило 2: Якщо бачиш слід — йди за ним
- Результат: складна система доставки їжі, оптимальні маршрути

**Для Britanka:**
- Прості правила Британки + унікальні агенти = унікальні раунди
- Не треба писати сценарій — він виникає сам
