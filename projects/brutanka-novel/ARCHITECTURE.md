# BRITANKA ENGINE — Архітектура

## Концепція

Двіжок для генерації дебатних раундів між AI-агентами з унікальними особистостями. Кожен раунд = міні-новела: діалоги, емоції, стратегії, несподівані повороти.

---

## Шари архітектури

```
┌─────────────────────────────────────────┐
│  LAYER 4: NOVELA                        │
│  — Сюжет, сцена, драматургія            │
│  — Описи, думки персонажів, напруга     │
├─────────────────────────────────────────┤
│  LAYER 3: DEBATE                        │
│  — Правила Британки (BP)                │
│  — Таймінг, POI, ролі                   │
│  — Суддівство, бали                     │
├─────────────────────────────────────────┤
│  LAYER 2: AGENT                         │
│  — SOUL.md (особистість)                │
│  — CORE.json (параметри)                │
│  — Стратегія, емоції, пам'ять           │
├─────────────────────────────────────────┤
│  LAYER 1: SIMULATION                    │
│  — LLM-інференс                         │
│  — Контекстне вікно                     │
│  — Промпт-інжиніринг                    │
└─────────────────────────────────────────┘
```

## Компоненти

### LAYER 1: SIMULATION

**Ядро:** LLM (OpenRouter / Claude / GPT)

**Завдання:**
- Генерувати текст промови за промптом
- Враховувати контекст (попередні виступи, POI)
- Повертати структурований результат (текст + метадані)

**Аналогія:** Це як актор на сцені, який отримує режисерські вказівки і імпровізує в рамках ролі.

---

### LAYER 2: AGENT

**Вхід:** SOUL.md + CORE.json

**SOUL.md** — "душа" персонажа:
- Ім'я, бексторі, мотивація
- Стиль мови (холодний, пристрасний, іронічний)
- Сильні/слабкі сторони
- Тригери (що виводить з рівноваги)

**CORE.json** — "математика" персонажа:
```json
{
  "cooperation_bias": 75,      // схильність до командної гри
  "deception_tendency": 30,    // агресивність, хитрість
  "strategic_horizon": 60,     // далекоглядність
  "risk_appetite": 45          // готовність ризикувати
}
```

**Пам'ять агента:**
- Короткострокова: поточний раунд
- Довгострокова: попередні дебати, репутація інших агентів

**Аналогія:** SOUL — це характер актора, CORE — його технічні навички (імпровізація, робота з партнером, контроль сцени).

---

### LAYER 3: DEBATE

**Модуль правил:**
- Порядок виступів (PM → LO → DPM → ...)
- Таймінг (7 хвилин, protected time)
- POI механіка (запит → прийняття/відхилення → відповідь)
- Ролі та обов'язки (хто що має робити)

**Модуль суддівства:**
- Оцінка кожного виступу за критеріями
- Командний рейтинг (1-4 місце)
- Індивідуальні бали (50-100)

**Аналогія:** Це як шахова дошка з правилами — фігури рухаються за законами, але кожна гра унікальна.

---

### LAYER 4: NOVELA

**Сценарій:**
- Сеттінг (де відбуваються дебати)
- Стейки (що на кону)
- Тема та проблема

**Драматургія:**
- Описи реакцій (потіє, посміхається, б'є кулаком по столу)
- Внутрішні монологи ("Чорт, він мене підловив")
- Напруга між персонажами

**Аналогія:** Це як сценарій фільму — не просто діалоги, а кіно: камера, музика, емоції.

---

## Потік даних

```
1. Ініціалізація
   ├─ Завантажити агентів (SOUL + CORE)
   ├─ Обрати сценарій
   └─ Задати тему

2. Раунд
   ├─ Для кожного спікера:
   │  ├─ Сформувати промпт (SOUL + CORE + контекст + правила ролі)
   │  ├─ LLM генерує промову
   │  ├─ Обробити POI (якщо є)
   │  └─ Записати виступ + метадані
   └─ Судді оцінюють

3. Результат
   ├─ Командний рейтинг
   ├─ Індивідуальні бали
   ├─ Оновити пам'ять агентів
   └─ Згенерувати новелу (описи, діалоги, драматургія)
```

## Математична модель

### Оцінка виступу

Кожен виступ оцінюється за формулою:

```
Score = 0.4 × Content + 0.25 × Rebuttal + 0.25 × Structure + 0.10 × Style
```

Де кожен компонент — це функція від:
- Якості аргументів (LLM оцінка + евристики)
- Виконання ролі (чи зробив те, що мав)
- CORE-параметрів агента (наприклад, високий cooperation_bias → краща комунікація)

### Вплив CORE на гру

| Параметр | Вплив на дебати |
|----------|-----------------|
| cooperation_bias | Ймовірність підтримати партнера vs атакувати супротивника |
| deception_tendency | Частота POI, агресивність тону, готовність до "брудних" прийомів |
| strategic_horizon | Якість extension (для CG/CO), далекоглядність аргументів |
| risk_appetite | Готовність оскаржити definition, йти на нестандартні ходи |

### Функція ймовірності POI

```
P(POI) = f(deception_tendency, поточна_напруга, timing)
```

Агент з високим deception_tendency частіше перебиває і агресивніше атакує.

## Інтеграція з 4_agents

**Вхід:** Пайплайн 4_agents генерує SOUL.md + CORE.json

**Вихід:** Britanka Engine використовує їх як персонажів для дебатів

**Зв'язок:**
- CORE-параметри впливають на стратегію в дебатах
- SOUL задає стиль і характер
- Результати дебатів оновлюють "досвід" агента

---

## Масштабування

**Один раунд:** 8 спікерів × 7 хвилин = ~50 LLM-викликів

**Оптимізації:**
- Кешування контексту
- Паралельна генерація (POI незалежні)
- Стримінг для real-time ефекту
