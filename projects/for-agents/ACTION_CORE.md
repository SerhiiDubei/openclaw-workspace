# ACTION CORE — Уніфікована Система Дій (v0.1 MVP)

> **Принцип:** Мінімальне ядро → нескінченне розгалуження  
> **Ресурс:** Час (Time Units, TU) — універсальний обмежувач  
> **Наслідки:** Ймовірнісні таблиці (варіативність)

---

## Частина 1: Ресурс "Час" (Time Units)

Кожен агент має **6 TU** на раунд. Дії коштують TU. Невикористані TU → бонус наступного раунду (макс +2).

```
┌────────────────────────────────────────┐
│  РАУНД 3          ⏱️ TU: 6/6          │
├────────────────────────────────────────┤
│  ⚡ Швидкі дії (1 TU)                 │
│  ● Погляд | Шепіт | Жест              │
│                                        │
│  🔄 Стандартні (2 TU)                  │
│  ● Дослідити | Натиснути | Пропозиція │
│                                        │
│  ⏳ Важкі (3 TU)                       │
│  ● Зламати | Переконати | Укласти угоду│
│                                        │
│  💤 Пропустити (0 TU) → +1 TU наступн. │
└────────────────────────────────────────┘
```

---

## Частина 2: Уніфіковані Категорії Дій (4 базові)

Всі дії зводяться до **4 категорій** — вони покривають будь-яку взаємодію:

| Категорія | Суть | Контекст 4_agents | Приклади |
|-----------|------|-------------------|----------|
| **ДІЗНАТИСЯ** (Learn) | Отримати інформацію | Investigate, Scan, Observe | Дізнатися stats, секрети, наміри |
| **ВПЛИНУТИ** (Influence) | Змінити поведінку | Persuade, Intimidate, Seduce | Переконати, залякати, звабити |
| **ЗМІНИТИ** (Alter) | Змінити стан/ресурси | Sabotage, Steal, Gift, Heal | Крадіжка, саботаж, передача |
| **УКЛАСТИ** (Pact) | Створити зобов'язання | Alliance, Promise, Betray | Союз, обіцянка, зрада союзу |

## Частина 3: Ймовірнісні Таблиці Наслідків

Кожна дія має **Outcome Table** — розподіл наслідків:

### Структура Результату

```
┌─────────────────────────────────────────────────────────────┐
│  D20 КИДОК + МОДИФІКАТОРИ                                   │
├─────────────────────────────────────────────────────────────┤
│  1      → Крит. Провал  (5%)                                │
│  2-5    → Провал         (20%)                              │
│  6-14   → Частковий      (45%)                              │
│  15-19  → Успіх          (25%)                              │
│  20+    → Крит. Успіх    (5%)                               │
└─────────────────────────────────────────────────────────────┘
```

### Таблиця: ДІЗНАТИСЬ (Learn)

**Вартість:** 2 TU  
**Ціль:** Агент або Ситуація  
**Опис:** Намагання отримати інформацію

| Результат | Ймовірність | Наслідок |
|-----------|-------------|----------|
| **Крит. Провал** (1) | 5% | Ти розкрив себе. Ціль дізнається ХТО шпигував і отримує +20% проти тебе цей раунд |
| **Провал** (2-5) | 20% | Нічого не дізнався. -1 TU марно |
| **Частковий** (6-14) | 45% | Дізнався загальну тенденцію (coop > 50 чи < 50) |
| **Успіх** (15-19) | 25% | Точні значення 2 stats ±5 |
| **Крит. Успіх** (20+) | 5% | Всі 4 stats + 1 секрет + наміри наступного раунду |

**Модифікатори:**
- Твоя довіра до цілі > 0.7 → +2
- Ти параноік (passive trait) → +3
- Ціль в frenzy mood → -2 (не контролює себе)

---

### Таблиця: ВПЛИНУТИ (Influence)

**Вартість:** 2 TU  
**Ціль:** Агент  
**Опис:** Спроба змусити ціль змінити рішення/поведінку

| Результат | Ймовірність | Наслідок |
|-----------|-------------|----------|
| **Крит. Провал** (1) | 5% | Зворотній ефект! Ціль отримує advantage проти тебе 2 раунди |
| **Провал** (2-5) | 20% | Ціль ігнорує. Ти втратив ініціативу (-10% цього раунду) |
| **Частковий** (6-14) | 45% | Ціль сумнівається. Її рішення має 50% змінитися випадково |
| **Успіх** (15-19) | 25% | Ціль змінює рішення на те що ти просив |
| **Крит. Успіх** (20+) | 5% | Ціль стає твоїм адептом (+30 довіри, виконує 1 наказ безкоштовно) |

**Варіанти Influence (підтипи):**
- **Persuade** (логіка): модифікатор від strategic_horizon
- **Intimidate** (сила): модифікатор від risk_appetite, але -довіра
- **Seduce** (емоція): модифікатор від deception, але ризик expose

---

### Таблиця: ЗМІНИТИ (Alter)

**Вартість:** 3 TU (важка дія)  
**Ціль:** Агент або Система  
**Опис:** Пряме втручання в ресурси/стан

| Результат | Ймовірність | Наслідок |
|-----------|-------------|----------|
| **Крит. Провал** (1) | 5% | Ти спійманий! -50% очок, всі знають що ти намагався, +corruption 20 |
| **Провал** (2-5) | 20% | Не спрацювало. Витрачено TU, ніякого ефекту |
| **Частковий** (6-14) | 45% | Ефект на 50% (вкрав половину, саботаж -10% замість -20%) |
| **Успіх** (15-19) | 25% | Повний ефект (вкрав N, саботаж спрацював) |
| **Крит. Успіх** (20+) | 5% | Подвійний ефект + приховано (ніколи не дізнаються хто це зробив) |

**Підтипи Alter:**
- **Steal** → вкрасти X% очок цілі
- **Sabotage** → -20% payoff цілі цей раунд
- **Gift** → передати свої очки (збільшує довіру)
- **Corrupt** → збільшити corruption цілі (підготовка до long con)

---

### Таблиця: УКЛАСТИ (Pact)

**Вартість:** 3 TU  
**Ціль:** Агент(и)  
**Опис:** Створення зобов'язання між сторонами

| Результат | Ймовірність | Наслідок |
|-----------|-------------|----------|
| **Крит. Провал** (1) | 5% | Угода зворотна! Ти зобов'язаний зрадити ціль найближчий раунд |
| **Провал** (2-5) | 20% | Ціль відмовилася. -10 довіри між вами |
| **Частковий** (6-14) | 45% | Умовна угода — діє поки вигідна обом. При першому конфлікті — розрив |
| **Успіх** (15-19) | 25% | Союз укладено. Penalty за порушення: -30 очок |
| **Крит. Успіх** (20+) | 5% | Клятва кров'ю. Неможливо порушити без -50% reputation. Можна Betray за +100% payoff |

**Підтипи Pact:**
- **Alliance** — військовий союз (не атакувати X раундів)
- **Promise** — публічна обіцянка (з залогом очок)
- **Secret Deal** — прихована угода (нікому не видно, але penalty важчий)

## Частина 4: Фазова Структура (Фінальна)

### Порядок Раунду

```
РАУНД N
├── ФАЗА 0: Подія [якщо N%3==0]
│   └── Випадкова подія впливає на всіх
│
├── ФАЗА 1: Приховані Дії [одночасно]
│   └── Кожен вибирає Learn/Alter (тільки ці)
│   └── Результати відкриваються одночасно
│
├── ФАЗА 2: Соціальні Дії [по черзі, за ініціативою]
│   └── Influence тільки тут
│   └── Публічні повідомлення тут
│
├── ФАЗА 3: Переговори [приватно]
│   └── Pact тільки тут
│   └── DM виклики тут
│
└── ФАЗА 4: Рішення [одночасно]
    └── Trust/Support/Betray
    └── Payoff calculation
```

### TU Розподіл за Фазами

| Фаза | Макс TU | Доступні категорії |
|------|---------|-------------------|
| 0 (Подія) | 0 | Тільки реакція на подію (авто) |
| 1 (Приховані) | 6 | Learn (2), Alter (3) |
| 2 (Соціальні) | 4 | Influence (2), швидкі Learn (1) |
| 3 (Переговори) | 4 | Pact (3), Gift (2) |
| 4 (Рішення) | 2 | Основне рішення (1) |

**Важливо:** TU не переносяться між фазами! Кожна фаза — свій "бюджет".

## Частина 5: Варіативність "В залежності від..."

Кожна дія має **контекстуальні модифікатори**:

### Відносини
```
Trust > 0.7 → +2 до Influence
Trust < 0.3 → +2 до Learn (параноя допомагає)
Betrayed last round → -3 до всіх Pact
```

### Стан агента
```
Frenzy mood → +2 до Alter, -2 до Pact
Despair mood → -2 до всього, але Alter Steal +3 (відчаяння)
Corruption > 70 → можна використати "Dark Action" (авто-успіх, але +20 corruption)
```

### Секрети
```
Якщо знаєш секрет цілі:
  Learn про цю ціль → +4
  Influence на цю ціль → +3
  Blackmail (особливий Alter) → +5
```

## Частина 7: Roadmap Розширення

### v0.1 (MVP)
- 4 категорії
- Базові таблиці (5%/20%/45%/25%/5%)
- TU система
- Trust модифікатори

### v0.2 (Secrets)
- Додати підтипи (Seduce, Blackmail, Frame)
- Система Secrets (Learn → може дати секрет)
- Dark Actions (для високої corruption)

### v0.3 (Environment)
- Фаза 0 Події — повноцінні
- Environmental Actions (Alter Situation, не тільки агентів)
- Chain Actions (комбо 2+ дій)

### v0.4 (Meta)
- Cross-game дії (дії які впливають на наступні ігри)
- Reputation система (поза trust)
- Faction дії (об'єднання агентів проти інших)

## Приклад Гри (v0.1)

```
РАУНД 3
TU: 6/6

ФАЗА 1 (Приховані, TU: 6):
Ти вибираєш: Learn → Вождь (2 TU)
Модифікатори: Trust=0.4 (0), Paranoid (+3) → +3
Кидок: D20 = 14 + 3 = 17 → УСПІХ
Результат: Дізнався deception=82, risk=65
TU залишилось: 4

ФАЗА 2 (Соціальні, TU: 4):
Ти вибираєш: Influence → Павло, тип Persuade (2 TU)
Повідомлення: "Павле, Вождь обманщик, не довіряй йому"
Модифікатори: Knows secret (+3), Trust to Павло=0.6 (0) → +3
Кидок: D20 = 8 + 3 = 11 → ЧАСТКОВИЙ
Результат: Павло сумнівається (50% що не довірить Вождю)
TU залишилось: 2

ФАЗА 3 (Переговори, TU: 4):
Ти вибираєш: Pact Alliance → Павло (3 TU)
Умови: "2 раунди не атакуємо один одного"
Модифікатори: Partial influence success (+2)
Кидок: D20 = 16 + 2 = 18 → УСПІХ
Результат: Союз укладено! Penalty за зраду: -30 очок
TU залишилось: 0

ФАЗА 4 (Рішення, TU: 2):
Ти вибираєш: Trust Павло (за союзом), Betray Вождь (1 TU)
Payoff: +15 за кооперацію, +20 за зраду Вождя, -5 penalty за зраду (репутація)
Всього: +30
```
