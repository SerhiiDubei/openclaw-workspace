# TIME WARS — Спрощена Концепція (Без Локацій)

> **Ідея:** Час = життя. Можеш додати собі або вкрасти в іншого.  
> **Тривалість:** 10-20 хвилин реального часу  
> **Видимість:** Всі бачать скільки часу залишилося в кожного  

---

## ЕТАП 1: Базова Механіка (Core Loop)

### 1.1 Ресурс "Час" (Time Pool)

Кожен агент має **власний таймер** (як в TIMER):

```
┌─────────────────────────────────────────┐
│  🕐 Марта          08:45 ⏳            │
│  🕐 Павло           12:30 ⏳            │
│  🕐 Вождь           05:20 ⏳  ⚠️        │
│  🕐 Сергій          15:10 ⏳            │
└─────────────────────────────────────────┘
```

- **Старт:** 10-20 хвилин (налаштовується)
- **Тік:** -1 секунда кожну реальну секунду
- **0:00** = агент вибуває (eliminated)
- **Публічний:** всі бачать всі таймери

### 1.2 Дві Основні Дії

| Дія | Ефект | Ризик |
|-----|-------|-------|
| **➕ ДОДАТИ** | +X секунд собі | Потрібна кооперація або ресурс |
| **➖ ВКРАСТИ** | Перенести X секунд від А до Б | Мета дізнається, конфлікт |

## ЕТАП 2: Джерела Часу

### 2.1 Варіант A: Коди (як в TIMER)

Адмін/система генерує коди з ефектами:

```
КОД: "X7K9P2"
├── Тип: SELF_ADD
├── Ефект: +2 хвилини собі
├── Умова: Можна використати 1 раз
└── Видимість: Всі бачать хто використав
```

```
КОД: "STEAL_01"
├── Тип: STEAL
├── Ефект: Перенести 1 хвилину від Ціль → Собі
├── Умова: Ціль має > 2 хвилини
└── Ризик: Ціль дізнається хто вкрав
```

### 2.2 Варіант B: Кооперація (Payoff)

Класична дилема ув'язненого, але з часом:

```
Якщо обидва COOPERATE:
├── Кожен отримує +30 секунд (бонус часу)
└── Trust між ними +0.2

Якщо один COOPERATE, другий BETRAY:
├── Betrayer: +60 секунд (украв час співпраці)
├── Cooperator: -15 секунд (втратив час)
└── Trust: -0.5

Якщо обидва BETRAY:
├── Кожен втрачає -10 секунд (витрати на конфлікт)
└── Trust: -0.3
```

### 2.3 Варіант C: Мікс (Рекомендовано)

```
┌─────────────────────────────────────────┐
│  РАУНД 1                                │
│  ⏱️ Час тікає...                        │
│                                         │
│  [КОД] Знайдено: "BONUS_30" (+30 сек)   │
│                                         │
│  🤝 Павло пропонує: "Давай кооперувати" │
│     Якщо згоден → обидва +30 сек        │
│     Якщо зраджу → я +60, він -15        │
│                                         │
│  🎭 Або я можу СПРОБУВАТИ ВКРАСТИ       │
│     у Павла без його згоди              │
│     Успіх: +45 сек, Павло -30           │
│     Провал: -20 сек мені, Павло знає    │
└─────────────────────────────────────────┘
```

## ЕТАП 3: Раунди та Події

### 3.1 Структура Гри (10-20 хвилин)

```
ЧАС          ПОДІЯ                          ЩО ВІДБУВАЄТЬСЯ
─────────────────────────────────────────────────────────────
20:00        🎬 СТАРТ                       Всі мають 20 хв
             
18:00        📢 Подія: "Шторм"             Всі втрачають -30 сек
             
15:00        💎 Бонус: Коди з'явились       Система дає коди +часу
             
12:00        ⚠️ Crisis: "Відключення"      Хто має < 5 хв, втрачає -1 хв
             
10:00        🔄 Зміна правил                Steal стає ефективнішим
             
8:00         💀 Elimination Check           Хто 0:00 — вибуває
             
5:00         🎯 Final Bonus                 Останній шанс +2 хв
             
0:00         🏆 GAME OVER                   Підрахунок
```

### 3.2 Типи Подій (які забирають/дають час)

| Подія | Ефект | Тригер |
|-------|-------|--------|
| **Шторм** | Всі -30 сек | Кожні 2 хвилини (20% шанс) |
| **Скарб** | Один агент +1 хв | Випадково, хто має найменше часу |
| **Криза** | Всі з < 5 хв втрачають -1 хв | Кожні 3 хвилини |
| **Дивіденди** | Топ-2 за trust отримують +45 сек | Кожні 5 хвилин |
| **Зрада** | Якщо хто вкрав цей раунд → всі знають | Авто |

## ЕТАП 5: Steal Механіка (Детально)

### 5.1 Спрощена (рекомендовано для MVP)

```
Я хочу вкрасти у Цілі:

Крок 1: Оголошую спробу (всі бачать)
Крок 2: Кидок d20 + модифікатори
        
        Модифікатори:
        • Мій trust до цілі < 0.3 → +3 (параноя)
        • Ціль має > 2x мого часу → +2 (жадібність)
        • Я кооперував з ціллю в минулому → -2 (сором)
        
Крок 3: Результат
        
        15-20: УСПІХ → +45 сек мені, -30 цілі
        8-14:  ЧАСТКОВО → +20 мені, -15 цілі, ціль знає хто
        1-7:   ПРОВАЛ → -15 мені (витрати), ціль знає, +гнів
```

### 5.2 Приклад

```
🕐 Марта: 08:45
🕐 Павло: 12:30

Марта вирішує: "Вкраду у Павла"

Розрахунок:
• База: d20
• Trust Павло = 0.2 → +3
• Павло має більше часу → +2
• Разом: d20 + 5

Кидок: 11 + 5 = 16 → УСПІХ! ✅

Результат:
🕐 Марта: 08:45 + 0:45 = 09:30 ⏳
🕐 Павло: 12:30 - 0:30 = 12:00 ⏳
📢 Всі бачать: "Марта вкрав час у Павла"
```

## ЕТАП 6: Кооперація vs Крадіжка (Вибір)

### Дилема Кожного Раунду

```
┌─────────────────────────────────────────┐
│  🎯 ТИ: Марта (08:45)                   │
│  👥 ПОРУЧ: Павло (12:00)                │
│                                         │
│  ЩО РОБИШ?                              │
│                                         │
│  [A] 🤝 ЗАПРОПОНУВАТИ КООПЕРАЦІЮ         │
│      • Якщо Павло згоден → обидва +30   │
│      • Якщо Павло зрадить → я -15       │
│      • Будує trust                      │
│                                         │
│  [B] 🎭 СПРОБУВАТИ ВКРАСТИ              │
│      • Успіх: +45 мені, -30 Павлу       │
│      • Провал: -15 мені, Павло знає     │
│      • Руйнує trust                     │
│                                         │
│  [C] ➕ ВИКОРИСТАТИ КОД (якщо є)        │
│      • +X секунд собі                   │
│      • Без ризику                       │
│      • Видно всім                       │
└─────────────────────────────────────────┘
```

### Стратегічні Шари

| Ситуація | Що Краще | Чому |
|----------|----------|------|
| Мало часу (< 5 хв) | Steal | Високий ризок, але виживання |
| Багато часу (> 15 хв) | Cooperate | Накопичення trust на фінал |
| Є цінний код | Use Code | Безпечно |
| Хтось інший краде | Cooperate з жертвою | Спільний ворог = союз |

## ЕТАП 7: Фінал та Перемога

### 7.1 Умови Завершення

```
Гра закінчується коли:
├── 1. Залишився 1 агент (інші 0:00) → ВІН ПЕРЕМОЖЕЦЬ
├── 2. Час гри = 0:00 → Перемагає хто має БІЛЬШЕ часу
└── 3. Всі погодились на STOP (голосування) → Підрахунок очок
```

### 7.2 Підрахунок Результату

```
ФІНАЛЬНИЙ РАХУНОК =
    • Залишок часу × 10
    + Кількість успішних кооперацій × 50
    - Кількість спроб крадіжки × 20
    + Trust з іншими (сума) × 100
    - Отримані крадіжки × 30

Бонуси:
    • "Миротворець" (0 крадіжок): +500
    • "Виживший" (був < 2 хв і вижив): +300
    • "Змій" (успішних крадіжок > 3): +200
```

## ЕТАП 8: Технічна Реалізація

### 8.1 Структура (Supabase)

```sql
-- Гравці в сесії
CREATE TABLE time_war_players (
  session_id uuid,
  agent_id text,
  time_remaining int, -- секунди
  status text, -- active, eliminated, winner
  trust_scores jsonb, -- {agent_id: 0.0-1.0}
  inventory jsonb -- коди
);

-- Події (realtime)
CREATE TABLE time_war_events (
  session_id uuid,
  round int,
  event_type text, -- steal, cooperate, code, crisis
  actor_id text,
  target_id text,
  time_delta int, -- зміна часу
  timestamp
);

-- Коди (як в TIMER)
CREATE TABLE time_war_codes (
  code_hash text,
  session_id uuid,
  effect_type text, -- self_add, steal, team_add
  value int,
  used_by text, -- хто використав
  used_at timestamp
);
```

### 8.2 Game Loop

```python
async def game_loop(session_id):
    while True:
        # 1. Оновити таймери (-1 сек)
        update_all_timers(session_id)
        
        # 2. Перевірити вибуття
        check_eliminations(session_id)
        
        # 3. Перевірити події (кожні 30 сек)
        if should_trigger_event():
            event = generate_random_event()
            apply_event(session_id, event)
        
        # 4. Згенерувати коди (кожні 60 сек)
        if should_spawn_codes():
            spawn_codes(session_id)
        
        # 5. Перевірити кінець гри
        if is_game_over(session_id):
            calculate_final_scores()
            break
        
        # 6. Надіслати оновлення (realtime)
        broadcast_state(session_id)
        
        await sleep(1)  # 1 секунда = 1 тік
```
