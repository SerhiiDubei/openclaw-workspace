## Частина 3: 12 Дій Героя (The 12 Actions)

### Дії та їхні Залежності

Кожна дія використовує **3 параметри** як основу:

#### 1. АТАКА (Attack)
**Основа:** Сила + Вогонь + Бурхливість
**Опис:** Пряме агресивне діяння проти цілі
**Механіка:** d20 + (Сила.фізична + Вогонь.напір + Бурхливість.тиск)/15
**Outcomes:**

## Частина 4: Матриця Сумісності Дій

### Синергії (Дії що посилюють одна одну):
| Комбінація | Ефект |
|------------|-------|
| Розвідка + Атака | +50% точності (знаєш слабкість) |
| Натхнення + Творення | Подвійна якість продукту |
| Злякати + Маніпуляція | Ціль не може опиратися 2 раунди |
| Переконати + Зцілення | +100% ефективності зцілення |

### Конфлікти (Дії що слабшають одна одну):
| Комбінація | Ефект |
|------------|-------|
| Атака + Зцілення | -50% до обох (протиріччя) |
| Руйнування + Творення | Нульовий ефект (взаємне знищення) |
| Злякати + Переконати | Ціль заплутана (50% ймовірність випадкової реакції) |
| Втекти + Натхнити | Бігаєш колами (комунікація не працює) |

### Ланцюжки (Combo):
| Послідовність | Результат |
|---------------|-----------|
| Розвідка → Маніпуляція → Атака | Критичний удар без шансу на захист |
| Натхнення → Творення → Зцілення | Золота ера (всі бонуси ×3) |
| Злякати → Руйнування → Втекти | Терор (ціль в паніці 3 раунди) |

## Частина 5: Реалізація в Коді

### 5.1 Структура Параметрів

```python
@dataclass
class DodecahedronParam:
    """Один з 12 параметрів з 12 під-рівнями"""
    axis_name: str  # "fire_water", "earth_air", etc.
    value: int  # 0-100, 50 = balance
    
    # 12 sub-parameters
    sub_params: Dict[str, int]  # {"impulse": 25, "tempo": 75, ...}
    
    def get_pole(self) -> str:
        """Повертає домінуючий полюс"""
        if self.value < 30:
            return self.axis_name.split("_")[0]  # fire
        elif self.value > 70:
            return self.axis_name.split("_")[1]  # water
        return "balance"
    
    def get_modifier(self, sub_param: str) -> int:
        """Повертає модифікатор для кидка (0-5)"""
        return self.sub_params[sub_param] // 20

class CharacterDodecahedron:
    """Всі 12 параметрів персонажа"""
    
    AXES = [
        "fire_water", "earth_air", "light_shadow",
        "life_death", "mind_heart", "order_chaos",
        "individual_collective", "body_spirit", 
        "past_future", "strength_weakness",
        "submission_rebellion", "trust_suspicion"
    ]
    
    SUB_PARAMS = {
        "fire_water": ["impulse", "tempo", "pressure", "change", "spending", 
                       "response", "destruction", "passion", "spread", "warmth", 
                       "light", "ashes"],
        # ... інші 11
    }
    
    def __init__(self):
        self.params = {
            axis: DodecahedronParam(
                axis_name=axis,
                value=50,  # start at balance
                sub_params={sub: 50 for sub in self.SUB_PARAMS[axis]}
            )
            for axis in self.AXES
        }
    
    def calculate_action_bonus(self, action: str) -> int:
        """Розраховує бонус для дії"""
        action_params = {
            "attack": ["fire_water", "strength_weakness", "submission_rebellion"],
            "defend": ["earth_air", "body_spirit", "submission_rebellion"],
            "heal": ["life_death", "fire_water", "trust_suspicion"],
            # ... інші 9
        }
        
        params = action_params[action]
        bonus = sum(self.params[p].value for p in params) // 60  # avg / 20
        return min(bonus, 5)  # max +5
```

### 5.2 Резолюція Дії

```python
@dataclass
class ActionResult:
    action: str
    roll: int  # d20
    total: int  # roll + bonus
    outcome: str  # crit_fail, fail, success, crit_success
    narrative: str
    effects: List[Effect]

def resolve_action(
    actor: Agent,
    action: str,
    target: Optional[Agent],
    context: Context
) -> ActionResult:
    
    # 1. Базовий кидок
    roll = random.randint(1, 20)
    
    # 2. Бонус від параметрів
    param_bonus = actor.dodecahedron.calculate_action_bonus(action)
    
    # 3. Контекстні модифікатори
    context_bonus = calculate_context_modifiers(actor, action, context)
    
    # 4. Синергії/конфлікти з минулою дією
    combo_bonus = calculate_combo_modifier(actor, action)
    
    total = roll + param_bonus + context_bonus + combo_bonus
    
    # 5. Визначення результату
    outcome = determine_outcome(roll, total, action)
    
    # 6. Генерація наративу
    narrative = generate_narrative(action, outcome, actor, target)
    
    # 7. Застосування ефектів
    effects = apply_action_effects(action, outcome, actor, target)
    
    return ActionResult(
        action=action,
        roll=roll,
        total=total,
        outcome=outcome,
        narrative=narrative,
        effects=effects
    )

def determine_outcome(roll: int, total: int, action: str) -> str:
    """Визначає результат на основі кидка та суми"""
    if roll == 1:
        return "crit_fail"
    if roll == 20:
        return "crit_success"
    
    # DC залежить від дії та контексту
    dc = get_action_dc(action)
    
    if total < dc - 5:
        return "crit_fail"
    if total < dc:
        return "fail"
    if total < dc + 5:
        return "partial"
    if total < dc + 10:
        return "success"
    return "crit_success"
```

```python
def detect_archetype(dodecahedron: CharacterDodecahedron) -> str:
    """Визначає архетип на основі топ-3 параметрів"""
    
    # Сортуємо за відхиленням від 50
    dominant = sorted(
        dodecahedron.params.items(),
        key=lambda x: abs(x[1].value - 50),
        reverse=True
    )[:3]
    
    archetype_map = {
        ("fire_water", "strength_weakness", "submission_rebellion"): "Полководець",
        ("fire_water", "life_death", "trust_suspicion"): "Паладін",
        ("earth_air", "body_spirit", "past_future"): "Хранитель",
        ("air_earth", "mind_heart", "future_past"): "Візіонер",
        ("light_shadow", "life_death", "trust_suspicion"): "Месія/Зрадник",
        ("water_fire", "heart_mind", "chaos_order"): "Поет",
        ("shadow_light", "death_life", "suspicion_trust"): "Змій",
        ("individual_collective", "strength_weakness", "rebellion_submission"): "Бунтар",
        ("collective_individual", "weakness_strength", "submission_rebellion"): "Жертва",
    }
    
    key = tuple(d[0] for d in dominant)
    return archetype_map.get(key, "Унікальний")
```
