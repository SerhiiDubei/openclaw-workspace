## 9 Core Systems

### 1. **Audit & Logging System** 
*«Хто що виводить»*
- Трекінг всіх дій агентів та систем
- Логування рішень, діалогів, змін станів
- Відстеження ланцюжка причин-наслідків

### 2. **Storytelling Engine**
*«Придумує історії»*
- Генерація контексту для кожного раунду
- Атмосферні описи ситуацій
- Лор острова та ритуалів
- Зв'язування подій в оповідь

### 3. **Soul Generation System**
*«Фабрика персонажів»*
- Ритуал ініціалізації (12 питань)
- Генерація SOUL.md, CORE.json
- Створення BIO та STATES
- Верифікація цілісності персонажа

### 4. **Logistics & Transport System**
*«Переміщення та позиціонування»*
- Спавн агентів у сесії
- Розміщення в лоббі
- Телепортація між фазами
- Управління присутністю/відсутністю

### 5. **Game Emulation Engine**
*«Запуск та управління іграми»*
- Ініціалізація сесій
- Управління раундами (1-10)
- Перемикання фаз (dialog → decision → reveal → narrative)
- Обробка таймерів та таймаутів

### 6. **Mathematical Environment**
*«Симуляційне середовище»*
- Економічна модель (очки, баланс)
- Формули розрахунку результатів
- Ймовірності та випадковість
- Балансувальні коефіцієнти

### 7. **Information Control System**
*«Доступ до інформації»*
- Що бачить кожен агент
- Публічна vs приватна інформація
- DM канали
- Інформаційні бар'єри та сюрпризи

### 8. **Memory System**
*«Спогади агентів»*
- Short-term: поточна гра, контекст
- Long-term: попередні зустрічі, історія
- Емоційні асоціації (хто зрадив, хто допоміг)
- Просочування спогадів у рішення

### 9. **Persistence Layer**
*«Зберігання всього»*
- Game Logs: історія ігор для replay
- Agent Storage: файли агентів
- State Snapshots: чекпоінти сесій

## Можливі уточнення / розщеплення

### Альтернативний поділ (7 систем):

1. **Narrative Core** — об'єднати Storytelling + Information Control (обидва працюють з інфо-потоком)
2. **Agent Factory** — Soul Generation + Logistics (створення + розміщення)
3. **Game Engine** — Emulation + Mathematical Environment (ігровий цикл + правила)
4. **Cognitive Layer** — Memory System (чисто спогади)
5. **Audit System** — логування окремо
6. **Storage** — Persistence Layer
7. **Access Control** — можна винести окремо як Security Layer

### Розширений поділ (12 систем):

Додати:
- **Event Bus** — система подій/сповіщень між компонентами
- **Config System** — налаштування, баланс, параметри
- **Validation System** — перевірка цілісності даних
- **Scheduler** — таймери, відкладені задачі

## Питання для уточнення

1. **Storytelling vs Information Control** — чи це справді окремі системи? Обидві керують потоком інформації до агентів.

2. **Logistics** — чи це просто "розміщення агентів у кімнаті", чи складніше (шляхи, локації, переміщення між зонами)?

3. **Audit System** — чи це тільки для дебагу, чи частина геймплею (агенти можуть дізнаватись про минулі дії інших)?

4. **Mathematical Environment** — чи включає це тільки розрахунки, чи також фізику/простір?
