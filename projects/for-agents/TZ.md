# For Agents (4_agents) — Технічне Завдання

> **Актуальна версія** — синхронізовано з репозиторієм  
> **Архітектура:** FastAPI backend + Vite/React frontend + OpenRouter LLM

---

## 1. Огляд Проєкту

**Концепція:** 4 агенти-особистості проходять ритуал ініціації, отримують SOUL-профілі та зустрічаються в спільному середовищі для напружених, атмосферних рішень.

**Pillars:**
- Глибокий сторітеллінг і лор
- Відчутний ритуал ініціалізації (12 питань + SOUL)
- 4-гравцева взаємодія з чіткими правилами
- Технічно стабільна, передбачувана система

---

## 2. Поточна Архітектура

### 2.1 Backend (FastAPI)

**Основний файл:** `server/main.py`

**Pipeline ініціалізації агента:**
```
POST /generate-seed       → генерує сід + створює сесію
POST /generate-question   → наступне питання з контексту
POST /submit-answer       → застосовує відповідь, оновлює стан
POST /compile-soul        → компілює SOUL.md + CORE.json
```

**Game Engine** (`simulation/`):
- `game_engine.py` — 4 агенти, 10 раундів
- `dialog_engine.py` — генерація діалогів через LLM
- `payoff_matrix.py` — розрахунок нагород
- `reveal_skill.py` — механіка розкриття інформації

**Структура раунду:**
1. Dialog phase — публічні повідомлення + DM (через LLM)
2. Decision phase — кожен агент обирає дії (0.0-1.0)
3. Payoff phase — розрахунок нагород для всіх пар
4. State update — оновлення STATES.md та MEMORY.json
5. Reveal window — агенти можуть використати reveal skill

### 2.2 Frontend (Vite + React + Tailwind)

**Поточний стан:** `App.tsx` → тільки `<InitOpenPhase />`

**UI референс:** https://possumbilities.github.io/games.html

## 3. Рівні UI (Що потрібно реалізувати)

### Рівень 1: Ритуал Ініціалізації (Init Ritual)

**Стан:** Частково реалізовано (тільки InitOpenPhase)

**Флоу:**
1. **Екран входу** — створити нового агента / завантажити існуючого
2. **Seed генерація** — візуалізація створення світу
3. **12 питань** — по одному на екран, з анімацією друку
4. **Review відповідей** — перегляд перед компіляцією
5. **SOUL компіляція** — анімація "запису" профілю
6. **Результат** — показ SOUL.md + CORE.json, кнопка "Грати"

**Компоненти:**
- `InitOpenPhase` — вступний екран (✅ є)
- `SeedRevealScreen` — візуалізація сіда
- `QuestionCard` — карточка питання з прогрес-баром (1/12)
- `AnswerInput` — текстове поле + кнопка підтвердження
- `CompilationScreen` — анімація обробки
- `SoulRevealScreen` — фінальний результат

### Рівень 2: Лоббі та Підготовка

**Флоу:**
1. **Список агентів** — твої створені SOUL-профілі
2. **Вибір 4 агентів** — drag-drop або мультиселект
3. **Game setup** — налаштування параметрів (кількість раундів, складність)
4. **Pre-game briefing** — короткий вступ до сценарію

**Компоненти:**
- `AgentLibrary` — сітка агентів з аватарами
- `AgentCard` — мініатюра: ім'я, короткий опис, рівень
- `LobbyScreen` — вибір 4 учасників
- `GameSetupPanel` — слайдери налаштувань

### Рівень 3: Ігровий Процес (10 Раундів)

**Структура раунду:**

#### Фаза 3.1: Dialog (Максимум 3 ходи на агента)
- **Публічний чат** — всі бачать повідомлення
- **DM (Direct Messages)** — приватні повідомлення між парами
- **Таймер** — обмежений час на відповідь

**UI:**
- `DialogPhaseScreen` — розділений екран: чат + інформація
- `PublicChat` — лента повідомлень з аватарами
- `DMTray` — іконки для приватних повідомлень
- `TypingIndicator` — анімація "друкує..."

#### Фаза 3.2: Decision
- Кожен агент обирає дію по відношенню до інших (Cooperate/Betray на шкалі 0.0-1.0)
- Анонімно, одночасно

**UI:**
- `DecisionPhaseScreen` — вибір для кожного опонента
- `TrustSlider` — слайдер 0.0-1.0 з мітками
- `DecisionConfirm` — підтвердження вибору

#### Фаза 3.3: Reveal
- Показ результатів всіх пар
- Анімація розкриття рішень
- Підрахунок очок

**UI:**
- `RevealScreen` — матриця результатів 4×4
- `PayoffAnimation` — анімація зміни балансу
- `RoundSummary` — хто зрадив, хто підтримав

#### Фаза 3.4: Narrative
- Коротка історія/опис того, що сталося
- Контекст від Storyteller (LLM)

**UI:**
- `NarrativeCard` — текстова панель з атмосферним описом
- `ContinueButton` — перехід до наступного раунду

### Рівень 4: Мета-шар та Прогресія

**Після гри:**
1. **Game Summary** — фінальні бали всіх агентів
2. **Leaderboard** — рейтинг по всіх іграх
3. **Agent Evolution** — чи змінився SOUL після ігор?
4. **Replay** — подивитись лог гри

**Компоненти:**
- `PostGameScreen` — підсумок гри
- `LeaderboardTable` — таблиця лідерів
- `AgentEvolutionView` — порівняння "до/після"
- `GameHistory` — список минулих ігор

## 5. Технічні Вимоги

### 5.1 API Інтеграція

**Session Management:**
```typescript
// Створення гри
POST /generate-seed
{ "meta_params": { /* ... */ } }
→ { "session_id": "uuid", "seed": "...", "narrative": "..." }

// Ітерація питань
POST /generate-question
{ "session_id": "uuid", "context_index": 0 }
→ { "question": "...", "context_type": "..." }

// Відповідь
POST /submit-answer
{ "session_id": "uuid", "question_index": 0, "answer": "..." }
→ { "updated_state": {...} }

// Компіляція
POST /compile-soul
{ "session_id": "uuid" }
→ { "soul_md": "...", "core_json": {...} }
```

### 5.2 State Management

**Frontend:**
- Context API або Zustand для глобального стану
- React Query для API кешування
- Локальне збереження незавершених сесій

### 5.3 Real-time (Майбутнє)
- WebSocket для мультиплеєра
- Зараз: polling для статусу гри
