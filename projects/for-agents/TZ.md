# For Agents — Технічне Завдання

## Огляд проєкту
Розширена версія дилеми ув'язненого з AI-агентами. Гра з емуляцією різних сценаріїв, прокачкою персонажів та адмінським управлінням.

---

## Рівень 1: Авторизація та Ініціалізація

### 1.1 Екран входу
- **Варіант А**: Увійти в існуючий акаунт
  - Поле для ідентифікатора персонажа
  - Завантаження стану з бекенду
  - Перехід на головний екран (статистика)

- **Варіант Б**: Створити нового персонажа
  - Ініціалізація: ім'я, аватар (піксель-арт генератор)
  - Початкові stats (базові значення)
  - Перший рівень = 0 емуляцій

### 1.2 Піксель-арт генератор персонажів
- Унікальний візуал для кожного агента
- Параметри генерації (колір, форма, аксесуари)
- Експорт аватара в PNG/SVG

---

## Рівень 2: Головний Екран Гравця (Dashboard)

### 2.1 Профільна карточка
- Аватар (піксель-арт)
- Ім'я агента
- Поточний рівень
- Прогрес-бар: X/20 емуляцій до наступного рівня

### 2.2 Статистика
- **Загальна кількість ігор**: N
- **Вінрейт**: X%
- **Середній результат**: Y балів
- **Останні 5 ігор**: список з результатами

### 2.3 Лідерборд
- Топ гравців за рівнем/результатами
- Фільтри: за тиждень/місяць/все час
- Позиція поточного гравця

### 2.4 Кнопка "Грати"
- Перехід до вибору режиму гри

---

## Рівень 3: Система Рівнів та Прогресії

### 3.1 Механіка рівнів
| Рівень | Емуляцій потрібно | Нагорода |
|--------|-------------------|----------|
| 1 → 2  | 20                | +5 очок stats |
| 2 → 3  | 20                | +5 очок stats + новий скін |
| 3 → 4  | 25                | +10 очок stats |
| 4 → 5  | 25                | +10 очок stats + унікальний аватар |
| 5+     | 30                | +15 очок stats |

### 3.2 Розподіл Stats
Після підвищення рівня гравець отримує очки для розподілу:
- **Хитрість** (Cunning) — впливає на тактику обману
- **Співпраця** (Cooperation) — ймовірність довіри
- **Адаптивність** (Adaptability) — реакція на зміни
- **Агресія** (Aggression) — сила атаки/захисту

### 3.3 Візуалізація прогресії
- Анімований бар прогресу
- Поп-ап при підвищенні рівня
- Історія рівнів (коли які досягнуті)

## Рівень 4: Ігровий Процес

### 4.1 Вибір режиму
- **Одиночна емуляція** — 1 гра з випадковими агентами
- **Серія емуляцій** — N ігор поспіль
- **Турнір** — змагання з конкретними суперниками

### 4.2 Екран гри (Емуляція)
- Візуалізація раундів дилеми ув'язненого
- Відображення виборів агентів
- Підсумок раунду: хто що вибрав, скільки отримав
- Лог дій (історія ходів)

### 4.3 Результат гри
- Фінальні бали
- Зміна рейтингу
- +1 до лічильника емуляцій
- Перевірка на підвищення рівня

---

## Рівень 5: Адмін Панель

### 5.1 Управління емуляціями
- **Масовий запуск**: вказати кількість ігор (наприклад, 50)
- **Вибір учасників**: мультиселект агентів
- **Налаштування циклів**: параметри дилеми
- **Прогрес-бар**: відображення виконання

### 5.2 Управління агентами
- Список всіх агентів
- CRUD операції
- Перегляд статистики кожного
- Бан/розбан

### 5.3 Аналітика
- Графіки: кількість ігор за час
- Розподіл стратегій
- Топ стратегій по вінрейту
- Експорт даних (CSV/JSON)

### 5.4 Налаштування гри
- Зміна правил дилеми
- Баланс stats
- Параметри рівнів

## Рівень 6: UI/UX Референси та Стиль

### 6.1 Візуальний стиль
- **Pixel art** — ключова естетика
- **Палітра**: 8-bit/16-bit кольори
- **Анімації**: спрайтова анімація для персонажів
- **Шрифти**: піксельні (Press Start 2P, VT323)

### 6.2 Референси
- **Сайт-приклад**: https://possumbilities.github.io games.html
- **Стиль**: ретро-ігри, термінальний інтерфейс
- **Атмосфера**: кіберпанк + в'язниця (тема дилеми)

### 6.3 Компоненти інтерфейсу
- Кнопки з піксельними бордерами
- Термінальні вікна з "курсором"
- Міні-карти/схеми
- Glitch-ефекти для акцентів

## Розширений Варіант (Що можна додати)

### 7.1 Соціальні функції
- **Клани/гільдії** — об'єднання агентів
- **Чат** між гравцями
- **Дружні матчі** — запросити конкретного суперника

### 7.2 Поглиблена кастомізація
- **Скіни** — купівля/отримання нових виглядів
- **Титули** — досягнення ("Майстер обману", "Король співпраці")
- **Профільна сторінка** — публічний профіль з історією

### 7.3 Економіка
- **Валюта** — очки/токени за перемоги
- **Магазин** — скіни, бусти, преміум-фічі
- **Щоденні нагороди** — логін-бонуси

### 7.4 Просунуті режими
- **Кастомні правила** — гравці створюють варіації дилеми
- **Кампанія** — сюжетний режим з епізодами
- **PVP арена** — прямі дуелі 1v1

### 7.5 Технічні покращення
- **Офлайн-режим** — гра без інтернету
- **PWA** — встановлення як додаток
- **WebSocket** — реалтайм емуляції
- **API** — для сторонніх інтеграцій

### 7.6 Мобільна версія
- Адаптивний UI
- Touch-контроль
- Push-сповіщення

## Технічний Стек (пропозиція)

- **Frontend**: React/Vue + Canvas для піксель-арту
- **Backend**: Node.js/Python
- **База даних**: PostgreSQL + Redis для лідербордів
- **Генерація аватарів**: Canvas API або Python Pillow
- **Реалтайм**: WebSocket (Socket.io)
