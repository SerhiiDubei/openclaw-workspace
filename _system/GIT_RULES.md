# Правила роботи з Git — КРИТИЧНО

## Перед тим як сказати "готово" або "запушено":

1. **ЗАВЖДИ** виконати: `git status`
2. **ЗАВЖДИ** переконатися що: working tree clean
3. **ЗАВЖДИ** перевірити лог: `git log --oneline -1`

## Чому це важливо:
- Користувач не повинен перевіряти мою роботу
- "Готово" = дійсно готово, не "я сподіваюсь готово"
- Повторення помилок заїбує

## Шаблон відповіді про git:
```
Перевірка:
- git status: working tree clean ✓
- git log: коміт XXXXXXX
- GitHub: запушено ✓
```
