# Протокол дослідження вакансії

**Обов'язковий чекліст перед написанням cover letter.**

## Step 1: Збір інформації (ОБОВ'ЯЗКОВО)

### Компанія
- [ ] Відвідати сайт компанії
- [ ] Зрозуміти чим вони займаються (продукт / сервіс / агенція)
- [ ] Знайти цікавий факт / деталь про продукт
- [ ] Зрозуміти стадію компанії (стартап / scale-up / enterprise)

### Продукт
- [ ] Що це за продукт?
- [ ] Для кого (цільова аудиторія)?
- [ ] Яка проблема вирішує?
- [ ] Чим відрізняється від конкурентів?

### Вакансія
- [ ] Прочитати повний текст вакансії
- [ ] Виділити key requirements
- [ ] Зрозуміти чого саме шукають
- [ ] Знайти "red flags" (що не підходить)

## Step 2: Аналіз метчу

### Порівняти з моїми скілами
- [ ] Завантажити `references/my-skills-detailed.md`
- [ ] Пройтись по key requirements
- [ ] Позначити: ✅ Strong / ⚠️ Partial / ❌ Gap

### Оцінка релевантності
- **10** — Ідеальний метч, мої сильні сторони
- **7-9** — Добрий метч, є gaps але покриваються
- **4-6** — Середній, багато чого треба доводити
- **1-3** — Слабкий, домен незнайомий або досвід не той

## Step 3: Підготовка hook

### Формула
**[інформація з дослідження] + [моя рефлексія] + [комплімент / інтерес]**

### Приклади
❌ Погано: "Побачив вашу вакансію і вирішив відгукнутись"
✅ Добре: "Почитав про FinDrive — цікавий підхід до управлінського обліку, а не звітності для інвесторів. Виділяється з потоку CRM-систем"

## Step 4: Перевірка cover letter

### Перед відправкою
- [ ] Hook написаний на базі дослідження
- [ ] Досвід релевантний (не "останній час" = 2 роки назад)
- [ ] Цифри реальні
- [ ] Запитання конкретні
- [ ] Обсяг 100-150 слів
- [ ] Перечитано на граматику
