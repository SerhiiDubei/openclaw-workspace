# Детальні навички та компетенції

*Розширена інформація про скіли, яких немає в резюме але важлива для аналізу вакансій.*

## Технічні скіли

### API та інтеграції
- **Рівень:** Advanced
- **Досвід:** Інтегрував багато різних API в системи
- **Деталі:** Працював з REST API, webhook-ами, data flows
- **Приклади:** Інтеграції платіжних систем, аналітики, автоматизацій

### Data flows
- **Рівень:** Intermediate
- **Досвід:** Розумію як дані рухаються між системами
- **Деталі:** Працював з ETL-процесами, аналітикою, reporting

### Enterprise SaaS
- **Рівень:** Intermediate
- **Досвід:** Paydefi (B2B), Point2Web (agency SaaS)
- **Деталі:** Не чистий enterprise, але B2B з складними продажами

## Продуктові скіли

### Requirements writing
- **Рівень:** Advanced
- **Досвід:** 7+ років пишу PRD, user stories, acceptance criteria
- **Деталі:** Працював з Jira, Confluence, Notion

### Prioritization frameworks
- **Рівень:** Advanced
- **Знаю:** RICE, Value vs Effort, MoSCoW
- **Досвід:** Щоденне використання для roadmap

### Stakeholder management
- **Рівень:** Advanced
- **Досвід:** Робота з C-level, командами, клієнтами
- **Деталі:** Вмію казати "ні" з обґрунтуванням

## Доменні області

### Fintech
- **Рівень:** Advanced
- **Досвід:** Paydefi (crypto payments), CRO для фінансових продуктів
- **Деталі:** Розумію платіжні flows, конверсію, B2B продажі

### AI/ML продукти
- **Рівень:** Advanced
- **Досвід:** Songer AI, Point2Web (AI інтеграції)
- **Деталі:** 10+ AI інструментів, ML курс

### Agtech / Farm Management
- **Рівень:** None
- **Досвід:** Немає
- **Примітки:** Потрібен час на вивчення домену

### ERP системи
- **Рівень:** Basic
- **Досвід:** Обмежений
- **Примітки:** Розумію концепцію, але не працював глибоко

## Мови

- **Українська:** Native
- **Англійська:** Upper-Intermediate (B2)
- **Польська:** Basic

## Інше

### Фінансове моделювання
- **Рівень:** Intermediate
- **Досвід:** Створював prediction моделі для продуктів
- **Деталі:** Як додатковий інструмент, не основна компетенція

### CRO (Conversion Rate Optimization)
- **Рівень:** Advanced
- **Досвід:** Point2Web, MTRX Agency
- **Результати:** +50%, +30%, +25% конверсії
