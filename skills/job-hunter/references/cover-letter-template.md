# Шаблон Cover Letter (ОНОВЛЕНО)

## Мова

**ОБОВ'ЯЗКОВО українською.** Англійська тільки якщо вакансія вимагає спеціально.

## Структура (4-5 абзаци, max 400 слів)

### 1. Match Summary (ОБОВ'ЯЗКОВО — 1 абзац, 2-3 булети)
Конкретні матчі requirements з JD ↔ твій досвід з метриками.

```
Match: Ви шукаєте [requirement] — я [робив що] з результатом [метрика].
Match: Для [конкретної сфери] — [твій досвід].
```

### 2. Hook (1 речення — рефлексія, не факт)
**Формула:** [особистий досвід/спостереження] + [їхня проблема/фічер] + [питання]

❌ Погано: "When I saw [Company] launched [product], I knew..."
✅ Добре: "Запускав fintech з 0 до 100K MAU — стикався з тим же викликом: як зробити onboarding швидшим за 3 хвилини."

### 3. Deep Dive (1-2 абзаци)
**Формула:** [ЩО робив] → [ЯКИЙ результат з цифрами] → [ЯК це релевантно вакансії]

Конкретні досягнення, прив'язані до requirements з JD. Тільки релевантний досвід.

### 4. Gap Address (якщо потрібно — 1 абзац)
1. Чесно вказати gap
2. Показати transferable skills
3. Додати готовність закрити gap

### 5. Questions (1-3 штуки — змінна кількість)

**Критично важливо:** питання мають бути **простими** і **продовжувати діалог**, не ставити рекрутера у глухий кут.

❌ Погано (складні, технічні):
- "Який retention ви бачите як healthy для вашого етапу?"
- "Як зараз виглядає інфраструктура для A/B-тестів?"

✅ Добре (прості, про процеси/людей):
- "У вас взагалі є план на наступні півроку — що конкретно хочете зробити?"
- "Скільки людей у команді і з ким найтісніше працюватиму?"
- "Процеси вже налагоджені чи ще формуєте?"
- "Який зараз основний pain point — з чим боляче?"

**Кількість питань:**
- Сильний match → 1-2 питання
- Середній match → 2 питання
- Багато невідомого → 2-3 питання-кларифікації

### 6. Call to Action (1 речення)
❌ Погано: "I look forward to hearing from you"
✅ Добре: "Готовий на 15-хвилинний колл — обговорити, чи можу бути корисним на вашому етапі growth."

---

## Повний приклад структури

```
Match: Ви шукаєте PM з досвідом retention-оптимізації — у мене 2+ роки, збільшив Day-7 retention з 18% до 31% через funnel-аналітику. Для mobile: досвід роботи з mobile dev team, хоча запускав веб-продукти.

Запускав fintech з 0 до 100K MAU — стикався з тим же викликом: як зробити onboarding швидшим за 3 хвилини. Налаштовував Mixpanel-funnels, знайшов drop-off на етапі верифікації, скоротив час проходження на 40%.

Прямого досвіду з mobile app не маю, але проходив курс Advanced Mobile Growth від Reforge, розумію специфіку ASO та mobile retention. Готовий закрити цей gap за перші 2-3 місяці.

Питання:
- Яка зараз конверсія в first transaction і який retention бачите як healthy для вашого етапу?
- Скільки людей у продуктовій команді?

Готовий на 15-хвилинний колл — обговорити, чи можу бути корисним на вашому етапі growth.
```

## Чекліст перед відправкою
- [ ] Match Summary є і містить конкретні цифри
- [ ] Hook — рефлексія, не пустий комплімент
- [ ] Досвід описано за формулою: [що] → [результат] → [релевантність]
- [ ] Gaps адресовані чесно (якщо є)
- [ ] Немає фраз типу "працював з X без контексту"
- [ ] Немає декларативних "вражає/цікавий продукт" без доказів
- [ ] Питання конкретні, з контексту їхнього продукту
- [ ] Менше 400 слів
- [ ] Перевірено на граматику
