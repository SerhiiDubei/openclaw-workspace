# Шаблон Cover Letter

## Структура (3-4 абзаци, max 400 слів)

### 1. Hook (1 абзац)
- Конкретна річ, яка привернула увагу до компанії/ролі
- Не: "I am writing to apply for..."
- Так: "When I saw [Company] launched [product], I knew..."

### 2. Value Proposition (1-2 абзаци)
- 2-3 ключових досягнення, релевантних до вакансії
- Метрики: "Increased X by Y%", "Reduced Z by N hours"
- Пряме зв'язування з requirements з job description

### 3. Motivation (1 абзац)
- Чому саме ця компанія
- Зв'язок між їх місією і твоїми цінностями
- Що ти можеш додати їх команді

### 4. Call to Action (1 речення)
- Коротко: прохання про інтерв'ю
- Не: "I look forward to hearing from you"
- Так: "I'd welcome the opportunity to discuss how I can help [Company] achieve [specific goal]"

## Чекліст перед відправкою
- [ ] Назва компанії правильна
- [ ] Назва ролі правильна
- [ ] Контактна особа (якщо відома)
- [ ] Жодних generic фраз
- [ ] Мінімум 1 конкретна метрика
- [ ] Менше 400 слів
- [ ] Перевірено на граматику
