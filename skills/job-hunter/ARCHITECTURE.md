## 🔄 Пайплайн (чіткий порядок дій)

### Крок 0: Отримання вакансій
**Дія:** Отримати batch вакансій від користувача
**Куди:** `00-inbox/{date}-raw-batch.md`

### Крок 1: Скринінг (Screening)
**Дія:** Відфільтрувати вакансії по критеріях
**Куди:** `01-screening/{date}-tier-distribution.md`
**Чекліст:**
- [ ] Фільтр по формату (remote/hybrid/office)
- [ ] Фільтр по індустрії (no iGaming якщо не хоче)
- [ ] Фільтр по досвіду (не junior)
- [ ] Розподіл на Tier 1/2/3

### Крок 2: Дослідження (Research)
**Дія:** Дослідити кожну Tier 1 компанію
**Куди:** `02-research/{company-name}/research.md`
**Чекліст:**
- [ ] Сайт компанії
- [ ] Продукт (що робить, для кого)
- [ ] Формат роботи
- [ ] Recent news/funding
- [ ] 2-3 цікавих факти

### Крок 3: Match Analysis
**Дія:** Порівняти requirements з резюме
**Куди:** той же `research.md`
**Чекліст:**
- [ ] Відкрити `references/my-resume.md`
- [ ] Відкрити `references/my-skills-detailed.md`
- [ ] Списати всі strong matches з метриками
- [ ] Вказати gaps (якщо є)

### Крок 4: Cover Letter
**Дія:** Написати кавер українською
**Куди:** `03-cover-letters/{company-name}/draft.md`
**Чекліст:**
- [ ] Match Summary (2-3 булети з цифрами)
- [ ] Hook (рефлексія, не пустий комплімент)
- [ ] Deep Dive (що → результат → релевантність)
- [ ] Gap Address (якщо потрібно)
- [ ] 1-3 прості питання
- [ ] CTA

### Крок 5: Рев'ю
**Дія:** Перевірити перед відправкою
**Чекліст:**
- [ ] Прочитати вголос
- [ ] Перевірити на "AI-slop" фрази
- [ ] Перевірити метрики (чи є в резюме)
- [ ] Довжина < 400 слів

### Крок 6: Відправка
**Дія:** Надіслати
**Куди:** перенести в `04-applied/{company-name}/`

```markdown
# Precoro — Дослідження

## Компанія
- **Заснована:** 2015
- **Продукт:** AI procurement platform для mid-market
- **Клієнти:** 1000+ companies, 80 countries
- **Фішка:** 95% accuracy в AI data extraction

## Вакансія
- **Роль:** Product Manager
- **Формат:** Hybrid (Київ)
- **Stack:** AI/ML, SaaS

## Match Analysis
✅ Strong: AI integration — 10+ нейромоделей, файнтюнінг
✅ Strong: Скоротив delivery time на 30% через AI
✅ Strong: End-to-end продуктовий цикл
⚠️ Gap: Немає досвіду в procurement (але є B2B SaaS)

## Нотатки
- Цікаво: "AI that gets the job done" — не AI для галочки
- Питання для cover letter: як пріоритизують AI-фічі?
```

### Приклад: 03-cover-letters/precoro/final.md
```markdown
# Precoro — Cover Letter (УКРАЇНСЬКОЮ)

Match: Ви шукаєте PM з AI-досвідом — впроваджував 10+ нейромоделей, робив файнтюнінг під задачі. Для B2B SaaS: скоротив delivery time на 30% через AI-автоматизацію.

На попередній роботі побудував систему генерації креативів на AI — від моделі до продакшену. Файнтюнив моделі під конкретні стилі. Це релевантно вам, бо ви робите AI-фічі, які мають реально закривати задачі procurement-у, а не "для галочки".

Питання:
- У вас є план на півроку — що конкретно хочете зробити?
- Скільки людей у продуктовій команді?

Готовий на 15-хвилинний колл.
```

## 🚫 Anti-patterns (чого НЕ робити)

❌ **Все в одну папку** — заплутуєшся через 3 вакансії
❌ **Назви без дат** — не зрозуміло що нове, що старе
❌ **Англійська без причини** — тільки якщо вакансія вимагає
❌ **Загальні фрази** — "AI Product Development" без контексту
❌ **Фіксовані 3 питання** — має бути змінна кількість
