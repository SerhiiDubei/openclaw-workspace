# Гіпотези для тестування

## Механіки

- [ ] **Бліц по колу** підходить для 10+ людей
  - Критерій успіху: engagement >80%, ніхто не вибуває дуже рано
  
- [ ] **Командні формати** дають вищий engagement ніж індивідуальні
  - Критерій: люди більше взаємодіють, менше телефонів
  
- [ ] **Донетки** краще працюють у другій половині гри
  - Критерій: більше правильних відповідей, вища енергія

## Складність питань

- [ ] **Складність 3** — оптимум для аудиторії 30-40
  - Критерій: ~60% правильних відповідей
  
- [ ] **Складність 1-2** для старту дає впевненість
  - Критерій: ~80% правильних, піднімає енергію

## Таймінг

- [ ] **30-40 хвилин** — оптимальна тривалість для бару
  - Критерій: люди не втомлюються, не йдуть раніше
  
- [ ] **Фаза старту** = 20% часу, але 40% енергії
  - Критерій: перші 10 хв задають тон

## Теми

- [ ] **Локальні теми** (Львів, Україна) краще за загальні
  - Критерій: більше обговорень, engagement
  
- [ ] **Поп-культура 90-х** = 30-40 аудиторія
  - Критерій: впізнаваність, емоційна реакція

## Формати

- [ ] **Circle формат** працює тільки до 12 людей
  - Критерій: люди не нудьгують в очікуванні
  
- [ ] **Бар-квіз** scalable до 40 людей
  - Критерій: команди не чують одна одну, не списують
