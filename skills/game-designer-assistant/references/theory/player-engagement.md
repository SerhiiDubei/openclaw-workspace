# Залучення гравців

## Фактори engagement

1. **Соціальний контакт** — гравці мають взаємодіяти
2. **Clear stakes** — що виграє переможець
3. **Comeback potential** — можливість наздогнати
4. **Skill expression** — простір для прояву знань
5. **Fun factor** — сміх, незвичні питання

## Типові проблеми

### "Dead time"
- Коли гравці чекають і нічого не роблять
- Рішення: паралельні активності, швидка зміна ходів

### Dominant player
- Один гравець знає все, інші відчувають себе дурними
- Рішення: командні формати, різні категорії

### Confusion
- Незрозумілі правила
- Рішення: спростити, демонстраційний раунд
