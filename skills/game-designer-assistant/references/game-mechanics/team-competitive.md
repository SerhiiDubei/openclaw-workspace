# Командні змагання

## Team Battle
- Дві команди змагаються head-to-head
- Питання чергуються між командами
- Можна steal після неправильної відповіді

## Командний Бліц
- Кожен гравець команди відповідає на 1 питання
- Сума очок = результат команди
- Швидка зміна гравців

## 1 проти Всіх (1vAll)
- Один гравець проти решти
- Спеціальні правила для балансу (наприклад, 2x бали для одного)
