# Quiz Formats

## Bar Quiz (Classic)
- Teams: 3-6 people per table
- Questions: displayed on screen or read aloud
- Answering: write on paper, collect after round
- Duration: 15-20 min per round
- Best for: 15-40 people, bars, pubs

## Blitz (Speed Round)
- One person, 10-20 questions rapid-fire
- Time limit: 30 sec per question
- Scoring: correct = +1, pass = 0, wrong = -1
- Best for: high energy, competitive individuals

## Circle
- Questions move around the group
- Each person answers one, then passes
- Best for: smaller groups (10-15), intimate setting

## Yes/No
- Binary answers only
- Fast pace, quick rounds
- Best for: warm-up, breaking ice
