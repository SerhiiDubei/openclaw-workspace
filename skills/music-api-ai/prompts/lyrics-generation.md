# Lyrics Generation — Генерація текстів

## Підходи

### 1. Власний текст
Користувач надає готові слова → обгортаємо в теги.

### 2. AI генерація
Просимо модель створити текст на тему.

## Формат

```
[Intro][Post Punk][Cold Wave]
Під прозорим покровом ночі

[Verse][Driving Bass][Ukrainian Lyrics]
Не побачу у дзеркалі очі

[Chorus][Energetic][Synth]
Текст приспіву тут

[Outro][Fade]
```

## Теги секцій

| Тег | Призначення |
|-----|-------------|
| `[Intro]` | Початок |
| `[Verse]` | Куплет |
| `[Chorus]` | Приспів |
| `[Drop]` | Дроп |
| `[Bridge]` | Брідж |
| `[Outro]` | Завершення |

## Мова

- **Англійська** — найкраща вимова
- **Українська** — прийнятна, може бути акцент
- **Змішана** — 50/50 працює добре
