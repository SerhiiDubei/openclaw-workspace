# Lyrics Generation — Генерація текстів (SunoAPI)

**⚠️ ТІЛЬКИ SunoAPI — НІ MusicAPI.ai!**

## Формат

```
[Intro][Post Punk][Cold Wave]
Під прозорим покровом ночі

[Verse][Driving Bass][Ukrainian Lyrics]
Не побачу у дзеркалі очі

[Chorus][Energetic][Synth]
Текст приспіву тут

[Outro][Fade]
```

## Теги секцій

| Тег | Призначення |
|-----|-------------|
| `[Intro]` | Початок |
| `[Verse]` | Куплет |
| `[Chorus]` | Приспів |
| `[Drop]` | Дроп |
| `[Bridge]` | Брідж |
| `[Outro]` | Завершення |

## Мова

- **Англійська** — найкраща вимова
- **Українська** — прийнятна, може бути акцент
- **Змішана** — 50/50 працює добре

## Підходи

1. **Власний текст** — користувач дає слова, обгортаємо в теги
2. **AI генерація** — просимо модель створити текст на тему
