## Technical Notes

### Проблеми які вирішили:
1. **SENSITIVE_WORD_ERROR** — деякі назви бендів (Pink Floyd) тригерять фільтр SunoAPI
2. **Правильний workflow для upload-cover:**
   - Завжди брати найсвіжіший файл з `/root/.openclaw/media/inbound/`
   - prompt має бути порожнім для збереження оригінального вокалу
   - style — тільки музичні терміни, без описів
   - audioWeight: 0.6-0.95 залежно від того, наскільки сильно змінювати оригінал

### JSON формат для upload-cover (правильний):
```json
{
  "uploadUrl": "https://.../file.mp3",
  "customMode": true,
  "instrumental": false,
  "model": "V5",
  "callBackUrl": "https://httpbin.org/post",
  "prompt": "",
  "style": "Trip-hop, slow beats, minor key",
  "title": "Track Name",
  "audioWeight": 0.6,
  "styleWeight": 0.5
}
```
